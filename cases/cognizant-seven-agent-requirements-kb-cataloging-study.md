# Cognizant企业知识层：七Agent逆向241仓库，再按服务限定业务规则检索

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-26
阶段：分析测试

2026年10月26日16:30（北京时间）的候选转录了Garima Agrawal等Cognizant研究者的论文《Reimagining Enterprise RAG for Multi-Agent Systems: A Knowledge Layer That Organizes Before It Retrieves》，标注arXiv:2610.32851v1、原始日期2026年10月23日。这是本轮分享的既有研究，不把论文日期改为本轮实验日期。

目标是企业应用的未文档化业务行为，而非破解二进制。作者报告自建七Agent逆向流水线，分析18个服务的241个仓库，生成带源码引用的范围定义、用户旅程、业务规则、验收条件及差异清单。14条业务流程中的一条最多涉及112份端点需求文档；offer、eligibility等词在不同服务中相似却不通用，平坦向量检索可能引用错服务的规则。

其知识层按服务、领域、功能和产物类型建立目录、稀疏元数据注册表及产物级超图，先解析问题为产物ID集合，再仅对该集合做dense/BM25混合检索。LLM置信门认为证据不足时扩大到全库；运行时上下文图保留规则到仓库的引用路径，供开发者核验。作者称一周内构建、18个服务接入无须修改schema，已辅助分析100多个生产缺陷，并把35次发布回归失败归因到规则和服务。不能将“分析100多缺陷”写成全部自动修复。

部署与数字均来自候选转录的论文陈述；没有获得企业仓库、缺陷单或独立运行记录。候选正文在Evidence blocked说明处结束，但此前足以辨认方法与有限结果。检索准确率仍在评估，没有可比准确率、扩库比例或消融数据，不将该设计说成已证实优于全部RAG。REA使用未提及，未执行目标。

原研究日期2026-10-23；本轮候选分享日期2026-10-26。
