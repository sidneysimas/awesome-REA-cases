# Toolport：含 REA 的371工具配置减少初始上下文的报告

分类：应用与客户端 · REA
记录日期：2026-10-18
阶段：分析测试

10月18日17:58（北京时间），Toolport宣传帖以他人的配置为测量对象：总计371个工具，其中REA占207个，启动前加载358K tokens；使用Toolport后初始上下文为19.1K，声称371工具仍能工作。具体问题是工具schema预载开销，不是原软件重建正确率。

同日23:21，@btsouth补充称已用REA 6.7.0与Ghidra，在两款去符号crackme上每种配置跑5次，各种方式都解出相同答案，Toolport能找到所需REA工具。crackme是供练习逆向的小型挑战程序。作者把前文FuurinFuu数字归于预载所有工具的ZCode，并称同样预载的OpenCode 1.19用Toolport后tokens减少6.1倍、速度提高3.2倍；Claude Code、Codex及OpenCode v2已有工具搜索，因此这些token收益不适用。这里按每种配置5次记录，不推算未说明的配置总数或总运行数。

这是新增作者自测主张，不是公开可重复基准。未给样本、完整配置、模型、token计数器、逐次日志或答案，无法核实同条件、所有工具功能或准确率。358K/19.1K是初始上下文，不能等同任务总成本；6.1倍与3.2倍不能推广到所有客户端，也不与LeanREA的36次对照混同。本合集未独立重跑。

10月18日原候选快照9赞、377浏览；358K／19.1K为初始上下文，非全任务成本或输出长度。
10月18日23:21补充候选快照1赞、14浏览；每配置5次及6.1倍/3.2倍仅为作者报告，没有公开原始记录。
