# Toolport：含 REA 的371工具配置减少初始上下文的报告

分类：应用与客户端 · REA
记录日期：2026-10-18
阶段：分析测试

10月18日17:58（北京时间），Toolport宣传帖以他人的真实配置为测量对象：总计371个工具，其中REA占207个，启动前加载358K tokens；使用Toolport后初始上下文为19.1K，声称所有371工具仍能工作。具体问题是逆向工具schema预载带来的上下文开销，不是从目标二进制恢复代码的正确率。

候选未提供可核验配置、模型与token计数器、逐工具调用记录或任务基准，无法确认量测条件一致或所有工具完整可用。不据此计算普遍节省比例，也不与LeanREA的36次任务对照混同；数值是作者测量主张，未独立重跑。

10月18日候选快照9赞、377浏览；358K／19.1K为初始上下文，非全任务成本或输出长度。
