# ScanSnap iX500：官方应用失效后用 Claude 做 Mac 扫描端

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-15
阶段：待验证

Jonas Wagner（@jonaswagnr）长期用 ScanSnap iX500 维持无纸化工作流，报告 ScanSnap Home 在 macOS 27 上失效，连带使设备无法按原方式使用。他称花一个晚上用 Claude Code 制作自己的 Mac 应用，支持 Wi-Fi 扫描、机身按钮、OCR 文字识别和去掉空白页，明确把它介绍为自己的逆向作品。补查原作者串确认身份，但未找到对 Wi-Fi/USB 抓取方法的作者答复；不能补写协议细节、源码许可或更多型号兼容性。时间和功能均是作者自述，本合集没有运行设备或独立验收。

本窗口候选快照：2赞｜52浏览；一晚为作者报告，不是测得工时。
