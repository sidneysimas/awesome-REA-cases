# 家居 App 协议：把无 API 设备接给本地 LLM

分类：硬件与设备互通 · REA
记录日期：2026-10-15
阶段：待验证

DiscusFish（@bitfish）认为买回来的智能家居仍被各自的遥控器割裂。他在 10 月 15 日的帖子中描述自己的集成方式：有 API 的设备直接调用 API，没有 API 的则用 REA 反编译 App、找出协议，再统一接到本地 LLM 调度。目标是让自购家居设备有统一的软件控制入口。原帖没有列出型号、协议细节、源码或逐设备测试结果；这是作者自述的集成报告，不能据此认定所有设备均支持本地离线控制，也不能与其他作者的全屋控制项目合并。
