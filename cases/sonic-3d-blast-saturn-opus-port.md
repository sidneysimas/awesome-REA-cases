# Saturn《Sonic 3D Blast》：字节匹配反编译与原生 PC 移植

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-16
阶段：进行中

10月16日 @TheOneMrMatt 回应质疑，承认 Opus 加速字节匹配反编译，称因反 AI 言论删除过说明。补查历史更新确认目标为 Saturn 版 Sonic 3D Blast：7月研究 SH2 代码和自制模拟器逐帧状态，8月3日称借 Claude Code 重建 Hitachi 编译环境，SSSS.BIN 特殊关卡引擎恢复为 C 与手写汇编并字节匹配，其余三个程序当时受特定 GCC 环境阻碍。9月26日称反编译进度100%，仍需多地区版本、文档和移植。10月16日06:04（早于本轮窗口）的更新描述 C/SDL 原生 PC 版、软件渲染后用 OpenGL 显示，支持宽屏与特殊关卡插帧；仍有边缘杂图和多边形接缝，计划11月20日首次发布，须自备 US/EU/JP 原盘文件。历史帖用于识别目标、AI用途与阶段，不是本轮新进展。匹配与画面表现均为作者报告，本合集未取得并运行源码，不把未来发布日期写成已发行。

本轮声明候选快照：0赞、14浏览；补证原帖从7月到10月16日，非本轮新成果。
