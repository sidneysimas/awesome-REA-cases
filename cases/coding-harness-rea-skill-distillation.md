# Coding harness 到 Skill：研究 Agent 编排实现的计划

分类：应用与客户端 · REA
记录日期：2026-10-18
阶段：进行中

10月18日06:06（北京时间），@YashasGunderia 说准备以 REA 研究 coding harness，即包裹模型、工具和工作流的编码 Agent 框架，再把研究结果蒸馏成 Skill 上传 GitHub，让其他 Agent 学着构建类似产品。他还称前一年已从 Claude Code 的源码做过类似工作，相关仓库接近40星，计划下个月更新 Claude 相关技能。

这是把软件实现研究转换成可复用 Agent 指导材料的进行中计划，不是恢复完整商业产品的完成报告。正文只给短链，本次未确认仓库、Skill 内容、复现效果或源码获取方式；接近40星是作者说法，不是本合集核实的仓库快照。REA 用于新计划，不能倒推到前一年的工作。作者关于合法学习任何在用软件的泛化法律断言不作为本合集结论，仍需遵守具体授权。
