# Hermes REA 插件：MCP 与适配 Skill 的发布转述

分类：应用与客户端 · REA
记录日期：2026-10-16
阶段：相关项目

一则转述帖称Hermes的官方REA插件已发布，一次安装带入REA MCP与为Hermes适配的reverse-engineer-anything Skill。帖子列出原生二进制、.NET、Electron、Android包、固件、浏览器捕获及进程活动等检查对象，称约170项工具放在工具搜索之后按需发现，以减轻上下文负担；安装入口写为hermes plugins install rea，要求Hermes 0.22.1及Node，原生反编译另需自备Ghidra、Hopper或IDA。它还称Skill要求运行程序或改变设备前先询问。发帖者最后说今晚安装，因此这不是其已完成的安装或目标分析验收；官方归属、版本、数量和权限提示均按转述保留，未在本轮安装或执行。与既有Hermes/WinSCP导入测试分开，作为集成项目说明，不推断所有Hermes版本都支持或所有操作都有强制拦截。

10月16日候选快照：6赞、549浏览；插件功能与约170工具是帖子口径，不是本合集实测。
