# Hermes REA 插件：MCP 与适配 Skill 的发布转述

分类：应用与客户端 · REA
记录日期：2026-10-16
阶段：相关项目

此前转述称Hermes官方REA插件一次安装REA MCP与适配的reverse-engineer-anything Skill，约170项工具通过工具搜索按需发现，覆盖原生二进制、.NET、Electron、Android包、固件、浏览器捕获及进程活动。帖子列安装入口hermes plugins install rea、Hermes 0.22.1及Node要求，原生反编译另备Ghidra、Hopper或IDA，并称Skill要求运行程序或改变设备前先问。原发帖者只是计划当晚安装，官方归属、版本、数量与权限提示仍是转述，非本合集安装测试。10月16日13:44 @wyant_dalto 回复称前一两天已给自己的Hermes加入REA及MCP，发现其Python逆向不足，并提及jadx 1.5.6、pycdc-rapid和Ghidra，称也已加到自己的配置。这是用户的集成经验与需求，不是官方Python兼容矩阵或全部软件均可逆向的证明；没有提供配置、目标样本、日志或验收测试。本合集未安装或执行，亦不把这些用户自加工具写成官方插件必带能力。与既有Hermes/WinSCP导入测试分开，不推断所有版本都支持或所有敏感操作都有强制拦截。
