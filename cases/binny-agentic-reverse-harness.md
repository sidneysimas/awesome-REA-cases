# BINNY：面向逆向研究的多模型 Agent harness 公测

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-16
阶段：相关项目

BINNY的发布帖将它介绍为面向逆向工程师和安全研究者的开源agentic AI harness，即为模型安排工具与执行流程的框架，称已进入public beta。具体主张包括多LLM支持、Ghidra集成、沙箱执行和自主二进制分析，用户自带模型，目标是减少重复分析工作。帖子附项目短链，但本次没有取得可检查的源码、许可证、具体目标或测试记录；开源、公测和这些功能均为发布者自述。尤其沙箱执行是产品主张，不代表已经证明没有副作用；没有确认使用REA。作为具体AI逆向相关项目收录，不写成完成某一软件分析的案例。
