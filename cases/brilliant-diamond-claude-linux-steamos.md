# Brilliant Diamond：Claude 研究音频库，把 Windows 重建版移到 SteamOS 的自述

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-19
阶段：待验证

10月19日03:25（北京时间），作者说找到只支持Windows的Brilliant Diamond反编译项目，让Claude移植到Linux，包括逆向音频库使其工作；随后生成Flatpak，经SSH安装到SteamOS并添加封面。作者称便携PC上从720p/30fps到1920×1080/120fps。目标是让既有重建版在自己的Linux掌机运行，而非声称Claude完成原始整游戏反编译。

未给项目仓库、音频库身份、构建、设备配置、画面与音频对照或帧率记录。所有分辨率、帧率与成功说法仅为作者自述，不确认稳定性、完整流程、原版兼容性或分发许可。REA未确认，未安装Flatpak或运行游戏。
