# JavaScript divergence：格式化后换游戏，误导 AI 逆向的 idea

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-17
阶段：相关项目

2026年10月17日17:20（北京时间），帖子介绍 Robert Vähhi 称为 divergence 的研究：利用JavaScript处理器的错误，使格式化或清理后的程序与原程序行为不同。帖中演示被描述为同一文件原先玩Tetris，格式化后玩Snake；例子是把“+ +m”变成“++m”，由不修改m变成自增。作者转述演示把这些差异串进一个小型虚拟机的字节码，以改变整款游戏，并称研究覆盖186种技巧、37个以上处理器。

与AI逆向的具体关系是防御idea：分析者或Agent先清理脚本，随后可能在一个仍能运行的诱饵上花费时间；若据此重建反机器人或反作弊客户端，服务器可能用行为差异识别副本。这并不证明某个AI Agent已被成功误导，也不说明所有格式化器都会触发，原帖明确依赖工具与配置。本条为具名研究的二手介绍与应用设想，未取得原演示代码、独立复现186种技巧或验证服务端识别效果；未确认REA参与。
