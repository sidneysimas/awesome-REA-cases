# 红星OS：REA在隔离虚拟机中分析文件审查与水印的转述

分类：应用与客户端 · REA
记录日期：2026-10-24
阶段：待验证

2026年10月24日07:48:03（北京时间），COCOA大学（@COCOA83421111）用日语概述一项对朝鲜Red Star OS（红星OS）的AI辅助逆向研究，目标是理解系统的文件审查与流转追踪机制。摘要说研究者在隔离虚拟机中构建2013年版系统，用REA分析内部程序，并称AI用约7至30分钟读懂以往专家研究过的可疑组件。它没有给原研究者姓名、程序路径、样本哈希或分析日志，因此不是本合集独立复现，也不是这些发现最早由AI作出。

摘要将系统描述为Linux基础、类似当年OS X的界面、主体历和面向境内网络的浏览器入口。技术部分转述常驻监控：打开文档、图片或视频时与约32MB禁用列表比对，命中后关闭应用、删除文件并发出警告；尝试停止监控会导致重启。另一部分称系统不必直接联网回报，而是在图片、PDF、Word等文件末尾追加加密的硬盘序列号，多台电脑的记录积累后可用于追踪流转。上述机制、适用文件、大小、时间与所谓完全追踪能力都仅据摘要；没有取得文件前后对照、解码程序或自保护测试，不能背书全部细节。

同窗口有多条相同日语视频标题的推荐，仅提供研究主题而没有新工件，不重复建案。原视频、系统镜像和代码未运行，未取得虚拟机或网络捕获。摘要末尾对数字主权、日本云依赖和CLOUD法的评论不作为该OS的技术测量。保留为具体且可追查来源的未验证分析报告，而非已证实的新漏洞或全版本结论。
