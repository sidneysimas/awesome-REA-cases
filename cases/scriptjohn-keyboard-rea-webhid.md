# 机械键盘配置到 WebHID：João 用 REA、Claude 与 Ghidra 替代 Windows 软件

分类：硬件与设备互通 · REA
记录日期：2026-10-22
阶段：待验证

2026年10月22日01:23（北京时间），João（@ScriptJohn_）回复AkitaOnRails，称自己的机械键盘只有一款体验很差的中国Windows软件，因此做了逆向，以WebHID API将其移到网页，并增加一些功能。他明确列出REA、Claude和Ghidra，构成从厂商配置工具到浏览器设备控制的具体替代用途。

原帖没有给键盘品牌型号、厂商工具版本、HID报告结构、增加了哪些功能、仓库或设备测试记录。不能推定支持所有机械键盘、跨浏览器兼容或已开源，也不能把它与已有GAMEKB-K17或Linux键盘工具记录合并。结果只归为作者自述，未运行网页或连接硬件，无法判断每个工具的具体分工。

来源更新：2026-10-22T01:23:37+08:00；WebHID 移植为作者自述，键盘型号与新增功能未公开。
