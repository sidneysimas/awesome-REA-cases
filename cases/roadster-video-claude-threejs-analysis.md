# Roadster 视频：Claude 辅助的 three.js 视觉拆解实验

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-17
阶段：分析测试

10月17日06:38（北京时间），@Flinzu 称从 Tesla Roadster 演示视频提取参考帧，交给 Claude Code 在无蓝图条件下研究外观与运动，再用 three.js 分离部件、标注并生成20秒拆解动画。帖子给出先确认轴距和车顶轮廓、每项断言对应画面、逐帧确定渲染的工作流；称最初盒状模型像玩具，先校正比例才改善，14个部件中6个看不见而标为未知。

这是从影像推断外形并可视化的作者报告，不是读取车辆软件或拆解真实硬件。升空、翻转、推力及“46百万浏览”等均来自该帖对视频的叙述，不能当成本合集核验的实车性能、结构、制造能力或热度快照。REA 只被拿来类比 App 分析思路，并未报告用于车辆；未检查视频原始真实性、模型代码或渲染结果，不将隐藏面板下的猜想当机械事实。

20秒与6/14部件未知为作者报告；没有核实车辆演示或内部机械结构。
