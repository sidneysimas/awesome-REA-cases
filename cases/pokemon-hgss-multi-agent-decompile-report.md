# 《宝可梦心金 / 魂银》：多 Agent 分块反编译的费用转述

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-16
阶段：待验证

一则回复称有人用多个AI Agent分别反编译《宝可梦心金》和《魂银》的片段，再将它们组合，一月内完成，累计约71 billion（710亿）token。帖子特别说这些不是本地模型token，而是Claude/OpenAI API，并称工作得到补贴，约56,000美元是按这些平台API用量估出的假设费用，不是实付账单。未提供开发者身份、仓库、匹配比例、测试或费用计算表，因此游戏范围、完成度、时间和token均保留为二手说法，不能认定clean room、没有使用既有公开成果或已完成可玩移植。本轮另一短讯仅重复心金一月和标价费用，未增加实质证据。REA未确认。

10月16日候选快照：1赞、22浏览；约710亿token、一月和56000美元均未经独立核验。
