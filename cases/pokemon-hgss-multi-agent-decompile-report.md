# 《宝可梦心金 / 魂银》：多 Agent 分块反编译的费用转述

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-16
阶段：待验证

此前一则回复称多个AI Agent分块反编译《宝可梦心金》和《魂银》，一月内组合完成，约71 billion（710亿）token，使用Claude/OpenAI API。它明确称工作得到补贴，约56,000美元是假设按API用量标价估算，不是实付账单。10月16日15:01 @Pirat_Nation 的新传播帖称心金全部4.1 MB编译代码恢复为可读C/C++，仓库也涵盖魂银，并声称能生成字节相同的ROM；这些完成度和匹配说法仍未从仓库或构建输出复核。15:25 @Alex_Vainshtein 回复指出项目建立在pret既有反编译和工具上，应分开衡量上游基础与Agent新增工作。这条归因提醒不等于已审计两者贡献，但明确阻止把总成果归为AI从零完成。未取得可核验仓库地址、匹配报告、开发者确认或费用表，不认定clean room、独立复现或已完成可玩移植；也不把新帖中“花费5.6万美元”的简化说法覆盖此前的补贴与假设费用边界。REA未确认。

较早10月16日候选快照：1赞、22浏览；约710亿token、一月和56000美元均未经独立核验。
15:01传播帖的10月16日候选快照：462赞、14048浏览、29转发；热度不是匹配或贡献比例的证明。
4.1 MB与字节相同ROM为二手报告；pret基础的提醒也未独立审计。
