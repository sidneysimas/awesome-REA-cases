# 旧 Humble Android 游戏：Codex 反编译与重编译以适配64位手机的自述

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-21
阶段：待验证

2026年10月21日05:48（北京时间），technosophist 说十年前买过一包 Humble Bundle Android 游戏，因它们是32位而无法在自己的64位手机运行，于是请 Codex 反编译、重编译，报告又能玩了。背景是已购买旧游戏与新手机兼容性，而不是新游戏创作或销售克隆。

原帖未命名游戏、手机、Android版本、原生库ABI、编译方法或代码，也无安装与运行对照。本合集不能确认是32到64位原生移植、兼容包装还是其他修复；不把作者对原因的判断升级成已核实机制，也不认为每台64位手机都不支持32位应用。REA未明示，结果未经独立复现。
