# 本机安全工具对照：作者称4模型360次零拒绝，固件检查正确性未明

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-28
阶段：分析测试

2026年10月28日01:57:11（北京时间），作者说在自己的机器用4个模型跑6个任务，列举找keylogger、网络扫描、SSH审计和路由器固件检查，报告360次没有拒绝，花1.48美元。点名Claude Opus、Qwen、DeepSeek但未列第四模型与全部任务；称Opus每次成本是Qwen的36倍。
