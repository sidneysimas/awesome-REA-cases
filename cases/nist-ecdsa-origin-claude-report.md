# NIST ECDSA 曲线：Claude 追溯公开参数的随机生成过程

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-17
阶段：分析测试

10月17日04:59与07:05（北京时间）的候选讨论 Claude 追溯 NIST ECDSA 曲线参数。ECDSA 用于数字签名，这里的问题不是恢复私钥，而是解释 NSA 提交、NIST 标准公开的曲线生成种子从何而来。补读10月16日 Anthropic 原始研究：团队称内部研究模型在不到半小时内识别 P-192、P-224、P-256、P-384、P-521 的种子由 C 库 lrand48 以 Unix 时间戳初始化生成。方法包括扫描相邻输出及高位模式、枚举隐藏位、用 LLL 格约化恢复截断生成器状态，再倒推 srand48 初始化。文章给出生成代码与输出，例如 P-256 对应1997-08-16 01:52:34 UTC及第1842个候选；本合集未执行代码。

研究还将 P-192 和五条 ANSI 示例曲线的基点联系到 FreeLIP zrandom，以小整数初始化并跳过七次输出；这与曲线种子的 lrand48 是两项不同发现，候选将二者笼统混合的说法在此更正。原文保留 B-163 种子、其他若干基点及为何跳过部分可用候选等未解问题，不能写成全部参数来源已解决。Anthropic 明确说不是密码学破解、新攻击或曲线弱点，也不要求用户改变使用方式。半小时和36,864美元奖金捐给 ISRG 均为团队报告；有公开算法与项目报告输出，但未经本合集独立复算。10月16日文章为补充原始来源，不计作本窗口新帖子，也不将 REA 的同期热度当作参与证据。

原始研究日期2026-10-16；窗口内候选为2026-10-17；未独立执行重算代码。
lrand48解释曲线种子，FreeLIP解释部分基点；不是恢复签名私钥或破解ECDSA。
