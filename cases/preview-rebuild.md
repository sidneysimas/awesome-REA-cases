# macOS 预览：有无 REA 的重建对照与自测边界

分类：应用与客户端 · REA
记录日期：2026-10-16

Preview（预览）是macOS自带的图片和PDF工具。Mahesh把重建它作为有无REA的对照，称纯Claude更快，REA版在缩放、分享、旋转、标注和保存上更接近原作。10月15日候选中文文章进一步叙述两条路线：REA侧解析CommonToolbar.plist、MainMenu.nib和私有selector，编写Swift实现并报告47项自测通过；另一侧依靠AppKit常识生成18个Swift文件并修复自身Bug，交付更快。10月16日新转述列出开图、裁剪、调色、导出和幻灯片功能，同时明确47项测试由AI自己编写、执行并设定及格线。这是对自测口径的重要限定，不是独立QA。新帖的“一句话、十分钟”仍缺可重放日志，不作为经核验全部工时。这些文章均未提供可重放源码与统一系统测试，属于对照的补充叙述，不是本合集或第三方独立复现；不采纳星数、私有类推断或速度差为普遍结论。
