# macOS 预览：对比有无 REA 的功能重建

分类：应用与客户端 · REA
记录日期：2026-10-12

Preview（预览）是 macOS 自带的图片和 PDF 查看工具。Mahesh 把重建它作为对照实验：一轮用 Claude + REA，一轮只用 Claude。作者称纯 Claude 更快完成，而 REA 版本在缩放、分享、旋转、标注和保存等功能上更接近原应用，绘图也更快。没有公开完整代码和系统测试；这是作者的一次对照报告，不是工具速度的普遍结论。
