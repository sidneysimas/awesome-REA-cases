# 开源应用发布包：Mia建议用REA辅助检查二进制是否对应源码

分类：应用与客户端 · REA
记录日期：2026-10-29
阶段：待验证

2026年10月29日02:26:06（北京时间），Mia（@MiaAI_lab）回复Zbigniew Majewski，建议试REA逆向检查。补查父帖（本窗口00:56:06）确认问题是：开源App的发布二进制是否真的来自公开源码、开发者会否在构建前改动，以及缺少可复现构建时是否只能信任CI。父帖举Tor、Bitcoin Core与部分Signal作可复现构建背景，不是已被REA分析的三个目标。

具体idea是把REA用于构建来源/行为核验；没有待检包、版本、差异证据、实验或结果。逆向观察可以提出疑点，但不能自动证明源码与二进制一一对应、代替确定性构建比较或证明无后门。只记录建议，未执行任何目标。
