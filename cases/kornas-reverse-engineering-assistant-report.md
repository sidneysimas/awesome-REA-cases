# Reverse Engineering Assistant：按文件生成离线分析报告的框架宣传

分类：应用与客户端 · 未确认使用 REA
记录日期：2026-10-17
阶段：相关项目

往期补审候选发表于2026年10月17日06:59（北京时间），Dan Kornas 介绍名为 Reverse Engineering Assistant（REA）的自主逆向框架，目标是让研究二进制、固件等材料的开发者不用先拼装许多工具。宣传的命令为 rea <file>，按内容识别格式，在目标旁输出 Markdown、PDF 和 JSON 报告；称支持二进制、固件、WebAssembly、SQLite、PCAP／HAR、source maps，静态报告涵盖适用的哈希、熵、导入导出与缓解机制。

帖子还称不用 AI API key 或联网也能退回确定性离线报告，并标为 MIT 开源。补读同作者回复确认提供了 GitHub 短链，但未识别仓库或检查实现，没有具体目标分析与测试记录。本轮将明确具名且有具体用途的工具宣传作为相关项目收录，不再仅因仓库未解而搁置；所有功能均保留宣传归因。Assistant 不能据同缩写混为 morluto 的 Reverse Engineer Anything，也没有证据将它归给 ReVa。离线报告不等于 LLM 完成语义恢复，未独立运行或确认其实际 AI 集成。

原 source window：10月17日04:00–08:00，北京时间；不是本轮新帖。
