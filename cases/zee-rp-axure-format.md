# zee-rp：让 AI 直接读写 Axure 原型文件

分类：应用与客户端 · REA
记录日期：2026-10-13
阶段：待验证

Axure RP 是交互原型工具。LilZee 的 computer use 临摹尝试失败后，研究 .rp 二进制格式，实现 LZ4 清单、.NET 类型化数据图与 GUID 引用处理，提供纯 JavaScript 引擎和 42 个 MCP 工具，让 Claude、Cursor、Codex 直接改文案、交互和中继器数据。作者在本周期回复中明确称使用 REA 辅助。公开 README 报告 225 个回归检查和原生应用保存重开样本，截图重建示例为 121 个可编辑元件；仅验证 macOS/Axure RP 11，Windows 未测试。结构、加载、预览行为与原生编辑验证分开声明，不能推成全格式支持；本合集未运行。与此前另一作者的 Axure 重建 idea 不是同一项目。
