# Skyworth 电视棒：Codex 将 Vidbox 网页包装改成遥控器界面的自述

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-20
阶段：待验证

10月20日19:38（北京时间）的候选回复询问 begottensun：廉价电视棒的遥控输入逆向是否只用 ADB。补读同日19:36父帖，作者 K（begottensun）称让 Codex 在20美元 Skyworth Android 电视棒上添加 Vidbox，最初得到网页包装，随后要求研究并改成适合遥控器输入的电视界面；再要求使用 Live API 做类似 Jarvis 的语音助手，声称一次完成，只要求 API key，并让用户打开开发者模式。

19:42作者回复说自己不知道具体用了什么，只记得工具要求把 Mac 与设备配对并给出界面。因而候选中的 ADB 仍是提问而不是已确认实现，语音助手是同一改造中的后续功能，不代表逆向获得 API。父帖与后续回复是候选上下文补证，不替代原候选；没有源码、设备精确型号、协议记录或测试，本合集未访问任何凭据、未运行设备程序，REA未明示。
