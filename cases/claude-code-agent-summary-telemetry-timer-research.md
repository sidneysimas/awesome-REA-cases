# Claude Code状态摘要：遥测成本研究与Bun定时器拦截的转述

2026年10月29日13:50:16（北京时间），爆裂队长NEXT（@thinkszyg）转述Flamerix AI对Claude Code后台Agent状态摘要的遥测研究，称一周快照中agent_summary占估计花费16.4%、主对话15.7%，并描述约30秒发送一次历史以生成3–5词状态。问题是不可见的辅助请求消耗预算，不是主任务本身的输出质量。

补读公开issue anthropics/claude-code #86879，创建于8月15日，早于本轮候选。正文报告2.1.233、darwin 25.6.0下的一次四小时、27子Agent会话：1496请求中339个状态摘要请求，约22.7%；按其Opus价格加权口径为18.0%，输出21966 tokens。原始token表占比22.2%与请求占比22.7%不是同一指标。issue展示bundle中的独立摘要调用、禁工具及不写主转录的分析，并请求官方关闭开关；读取时仍open，不等于官方已认可全部因果解释。

候选另称Flamerix约80行MIT Bun预加载钩子拦截摘要定时器，在2.1.257–2.1.312测试请求降至零，代价是面板状态不再刷新；macOS未测、Windows可能不生效，升级可失效。未取得并审查该脚本或全部测量，因此版本兼容、许可与零请求是转述。所谓美元消耗是按价估算，不是订阅额外扣款，也不能直接推断同等比例的订阅限额。

这是围绕AI客户端的具体逆向/遥测相关研究；来源没有说明研究者是否使用AI助手，故REA标unknown，而非因目标是Claude就认定AI辅助。本合集未访问本机遥测、凭据或配置，未安装钩子、停进程或复现测量。
