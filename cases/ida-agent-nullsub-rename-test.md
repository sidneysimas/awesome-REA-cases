# IDA Agent 自测：10 个 nullsub 逐条改名并还原

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-20
阶段：分析测试

10月20日00:19（北京时间），@mornpeak回复符号处理问题，称在IDB里选10个nullsub，让Agent循环调用单条rename，10/10改名成功、10/10还原，整轮不足1秒、热调用几毫秒。目标是测试AI连接IDA后的符号操作和撤销，不是某软件的逻辑恢复。

补读10月19日23:53父帖（早于本轮），作者称使用自行补充的98工具版本，并比较官方IDA MCP；父帖口语说批量改名，本轮明确是循环单条调用。上百符号分批和在IDA检查Undo是计划，非规模实测。无插件仓库、日志、模型或计时方法，REA未确认，不能推断多Agent共享IDB稳定性。
