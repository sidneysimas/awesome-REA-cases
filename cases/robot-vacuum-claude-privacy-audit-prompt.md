# 自有扫地机器人：让 Claude Code 检查远程窥视证据的调查提示词

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-20
阶段：待验证

10月20日09:21（北京时间），@tezzarc 发布完整提示词，让Claude Code调查用户自有扫地机器人是否可能被远程观看或监听。先从照片或About页面识别厂商、型号、固件、系统和摄像头/麦克风等硬件，再查询公开漏洞与厂商通告，核对视频、音频、地图、照片、遥测和云录制实际支持范围，并引导检查App的分享用户、会话、远程查看历史及警报。

若在本地运行，提示词要求测试前取得许可，只调查自己的网络设备；异常登录、未知分享和不明远控才是调查线索，普通云连接不能当作窥视证据。它明确禁止root、利用漏洞、绕过认证或访问他人设备；若厂商不提供日志，要报告无法确定。

这是具体的隐私调查idea与可复用提示词，不是某型号已被攻破或已安全的结论。来源没有实际型号、抓包、访问日志或执行报告，也未说明REA参与。本合集未扫描网络、检查账户或连接设备。
