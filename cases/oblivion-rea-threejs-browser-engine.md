# Oblivion 浏览器引擎：REA 笔记到 TypeScript／Three.js 的自述

分类：游戏与游戏保存 · REA
记录日期：2026-10-21
阶段：待验证

2026年10月21日03:23（北京时间），作者称为学习逆向，让 Claude 经 REA 反编译 The Elder Scrolls IV: Oblivion、记录详细笔记，再从笔记用 TypeScript 与 Three.js 写新游戏引擎。报告的用途是让原游戏在浏览器中运行，并由 Claude 随研究制作教学材料。

作者称实现从零编写，原资产作适配并从玩家自有副本读取，自己看到的是像完整游戏的运行画面。但未提供仓库、构建、覆盖机制或与原程序的行为对照；不能确认完整可玩、代码来源隔离或资产处理方式。作者强调这是付费请 Claude 做的工作，不是自己手写。这与 Oblivion Remastered 性能补丁是不同目标；本合集未运行游戏或独立复现。
