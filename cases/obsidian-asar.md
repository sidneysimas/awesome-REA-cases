# Obsidian：真实桌面包的大规模分析测试

分类：应用与客户端 · REA
记录日期：2026-10-12
阶段：分析测试

Obsidian 是本地笔记软件，桌面版的 JavaScript 可打包在 ASAR 归档中。用户用 REA 分析约 24MB 的真实包，修复后确认 REA 6.0.0 配合 JSONL 在 86 秒完成原目标。讨论证明大包分析可跑通，未展示从结果中重建某个笔记功能，因此标为分析测试，而非已完成的功能重建。



2026-10-15 一位发帖者自述先用 REA 分析 Obsidian，称完整性校验因原生二进制哈希不匹配而阻止首次运行，调整参数后数秒完成 JavaScript 层分析并看到文件读取及系统接口调用路径。其尝试分析原生二进制时失败，且未配置 Ghidra、Hopper 或 IDA；发帖者也明确指出仅有静态分析、动态 IPC 未解以及未运行代码不构成行为证据。帖子另提及一个未具名的大包并称耗时约一分钟，但目标身份和分析结果均不足以并入 Obsidian 案例。本合集未复现上述过程。

补充发帖：2026-10-15T00:29:18+08:00；作者自述，未独立复测。
报告限于 Obsidian JavaScript 静态分析；原生二进制分析失败，未证明动态行为。
