# Mauro 的 Mega Drive 移植：AI 将 DOS 游戏转为 C，人工处理内存与画面限制

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-19
阶段：进行中

10月19日10:03（北京时间），Mauro Xavier（@MXRetroDev）回应把其项目说成一次提示词生成 Rust 移植的玩笑，明确否认使用 Rust 和 REA。他取原 DOS 软盘版游戏，请 AI 尽量解释并转换代码为 C，使用面向 Mega Drive 开发的 SGDK 框架，再让 AI 转换与集成素材。目标是在不加增强芯片的原装 Mega Drive 上运行原游戏，而不是现代机器上的模拟版。

同串较早06:42的原作者帖报告已从头到尾通关、一次也未崩溃，但图形与性能仍待改善。该帖以截图让读者猜游戏，本轮可读文字未给游戏名；不从截图猜定作品，也不因此丢弃已有的具体工程说明。较早帖作为背景来源，不算本窗口新候选。

作者说明64 KB RAM和64 KB VRAM使直接移植遇到大量问题，需要自己调整。AI协助写 Python 工具，将若干多边形实体在指定位置预渲染，再写汇编做预渲染精灵的软件缩放。游戏有超过190个相机视角，未来还要人工改善Mega Drive色彩与抖动效果。作者强调完全交给AI不会得到相同结果；这些是AI承担大量工作但人工适配仍重要的自述，不是无人值守成功。

没有取得源码、ROM版本、构建记录、帧率测量或独立通关测试；不推断使用Claude或任何具体模型。通关与无崩溃只归于作者，未运行游戏或目标代码。
