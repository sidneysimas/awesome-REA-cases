# Anthropic红队多平台报告转述：Ghidra读Windows QUIC二进制并对照C重建

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-28
阶段：待验证

2026年10月28日22:31:17（北京时间），中文候选转述Anthropic于10月27日发布的红队研究，称未发布Claude参与多平台漏洞研究。最明确的逆向步骤是给模型无源码的Windows可执行文件，用Ghidra分析、写带注释的C重建、与原程序行为对照，再找到内核QUIC越界读，声称HTTP/3启用的设备可能崩溃重启。

同一研究报告转述还包括Chrome四漏洞串联：V8内存破坏、V8沙盒突破、CacheStorage竞态与FedCM释放后重用；Safari通过修改内存安全开关跨站读取；Linux多路径TCP竞态，作者说48分钟泄露地址再5分钟提权。帖子区分累计62项与此次52项Chrome修复，并给156.0.8078.73版本。这些数值、计算器演示与修复状态均为二手叙述，不是本合集重跑或系统安全建议。

没有取得原始研究全文、C重建、漏洞编号与补丁对照，模型身份和各链覆盖也未核实；仅按同一红队研究报告记录，不能称已证实任意网页可逃逸、所有平台已修复或仅二进制分析就能自动得到有效利用。REA未指明，未执行代码或测试漏洞。
