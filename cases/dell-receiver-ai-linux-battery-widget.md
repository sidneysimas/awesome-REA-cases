# Dell 键鼠：研究接收器协议，在 Omarchy 显示电量

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-20
阶段：待验证

10月20日17:34（北京时间），Mike Harrison（mikejharrison）报告，Dell 外设配套软件不支持 Linux，导致自己在 Omarchy 桌面看不到键盘和鼠标电量。他与 ChatGPT 研究接收器的通信协议，再让 Claude Code Agent 构建显示电量的小组件，目的是补齐原厂软件缺席时的桌面互通。

补查原帖确认作者身份与上述分工，帖子附有图片，但未提供键鼠及接收器型号、协议字段、源码或可重放测试。本合集没有读取设备或测量电量准确率，不能把小组件自述升级为适配全部 Dell 外设，也不能断言使用 REA。

原帖发布于2026年10月20日17:34（北京时间）；键鼠和接收器型号未披露。
