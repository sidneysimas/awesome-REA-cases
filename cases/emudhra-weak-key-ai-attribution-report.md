# eMudhra弱密钥：把公开数据恢复归因于AI与数学脚本的报道

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-23
阶段：待验证

2026年10月23日12:21:06及13:02:10（北京时间）的两则候选，摘录与详述eMudhra联合创始人Kaushik Srinivasan对ET的说法。本轮为往期补审，不是10月25日新事件。目标是从公开数据恢复证书机构弱密钥；AI角色来自当事人解释，不是本合集确认的工具链。

详述帖称2025年4月国际业务密钥生成的额外wrap-unwrap步骤有脚本错误，在正常强密钥外产生弱密钥；Srinivasan称其符合标准，但可用现代AI工具及运行数学算法的脚本逆向。帖中可预测秘密数值4、56、237及对检查、审计的质疑也都是报道内容，未检查任何密钥、证书或脚本，不能判断密码算法、模型贡献或攻击复杂度。

同帖转述公司否认基础设施入侵，称受影响机构在发现后14小时内撤销且未签发终端证书，并决定退出全球SSL/TLS证书业务；拟加强密钥仪式监督、maker-checker复核及AI强度检查。它同时称联合创始人以根因已知为由认为无需独立审计，另考虑让外部审计参与流程。未取得ET原文、官方调查、模型调用或可重放数学过程；时效、业务决定及未签发均只归因于该帖转述。记录具体但有争议的AI逆向归因，不证明AI打破正常强密钥、入侵基础设施或实际伪造证书，未访问密钥。
