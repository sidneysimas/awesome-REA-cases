# Ventris：用于源码与二进制安全研究的 Agent 平台转述

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-18
阶段：相关项目

10月18日18:17（北京时间），中文收购报道将Ventris描述为面向AI Agent的操作系统，用于分析源码与二进制，寻找漏洞、零日、恶意软件与后门；称支持自定义工作流并可在开源模型上运行。报道同时说Hex-Rays拟整合其能力；具体用途是为安全研究组织Agent流程，而非已经公开证明的一项漏洞发现。

六人团队、成立一年及3000万至3500万美元交易额均为报道主张，此处未独立核验，不以商业交易替代技术证据。候选没有公开仓库、模型、目标样本、误报数据或研究日志，不能确认各项检测能力、效率或已集成IDA。REA使用未确认，不执行产品或目标代码。

10月18日候选快照13赞、428浏览；商业新闻里的功能主张未独立验证。
