# 旧游戏存档到浏览器：用 REA 追规则与迁移进度的 idea

分类：游戏与游戏保存 · REA
记录日期：2026-10-18
阶段：待验证

2026年10月18日02:38（北京时间），@mika_systems 提出用Claude Code与REA让未通关老游戏的存档在浏览器重建版继续可玩。它不是某款游戏已移植的报告：原帖以第7关、3把钥匙作例子，要求保留关卡与物品状态。用户需有原游戏、可复用资产和存档副本，先在兼容环境跑原版并记录一整关，再研究缺失的移动、检查点和保存规则。

提议把调查、浏览器实现、旧存档字段映射与对照审查分开，使用相同状态和录制输入比较；验收链为读取旧存档、过关、保存、关浏览器、重开继续，并在干净会话导入导出存档复测。要求保留原文件，记录不能迁移的字段、缺资产和不支持格式。没有具名游戏、导入器代码或实际通过结果；这些是具体工作流idea，不是已验证存档兼容性。

来源：2026-10-18 02:38，北京时间；第7关/3把钥匙为示例，未有游戏或测试产物。
