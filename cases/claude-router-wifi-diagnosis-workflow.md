# 家用路由器：Claude 调查管理接口、诊断 Wi-Fi 与回读配置的流程

分类：硬件与设备互通 · REA
记录日期：2026-10-21
阶段：待验证

2026年10月21日03:06（北京时间），codila（0xCodila）称 Claude Code 逆向自家 Wi-Fi 路由器、五分钟找到并解决缓慢问题，并紧接发布完整提示词。具体路线是先尝试官方 API、开源库或 Home Assistant 集成，不行再研究管理页面的 JavaScript API，备份设置，检查频段、信道、带宽、模式、功率与负载延迟，再制作聊天中查询在线设备和请求重启的小工具。

04:46及05:24作者进一步解释，改Wi-Fi设置只是后半段运维：自家设备是 ISP 提供、运行其定制固件的 Huawei 路由器，没有公开API和内部文档。Claude 先读取后台面板代码，追踪登录、查询设备、Wi-Fi、重启所调用的内部端点与表单字段，还发现代码中有但菜单隐藏的内容，再写控制器，让聊天中的“谁在我的Wi-Fi上”能工作。作者明确说用了官方 REA 仓库的 skills；回取05:24原帖确认父帖是原03:06报告，故更正此前REA角色未确认的表述。这仍是作者的工具使用报告，不是独立检查端点。

原提示词要求可只诊断不修改，每次改动先展示新旧值并获同意、之后读回验证；不得更改网络名、密码、固件或恢复出厂，重启另行征求许可。密码应留在系统密码库，不进入聊天。这些是流程约束，不证明已正确实现。Huawei品牌与ISP定制背景已补充，但确切型号、固件版本、前后 Mbps、实际配置差异、隐藏功能明细或工具源码仍未提供，不能确认五分钟结果或“多数路由器可用”的宣传；本合集未连接或修改设备。
