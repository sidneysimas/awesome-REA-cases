# Motion2Code: coding agents rebuild reference motion videos as editable SVG and GSAP

A previously deferred candidate posted at 18:50 Beijing time on October 25, 2026 lists motion2code and animation-reverse-engineering as separate video-reconstruction tools. Public repository search identified lovisdotio/motion2code. The README read corresponds to the repository's latest commit, 0f003288997604487df04c1b7a0586900d3e36bb, dated October 20 at 04:21:50 UTC: earlier project material, not a new release in this window. It serves coding agents recovering editable animation from reference video or making real interactive sites from simulated website recordings.

The project first samples a frame every 0.25 seconds, frames around hard cuts, a contact sheet, colors and loop behavior, then builds SVG shapes on a single GSAP timeline. A seek(t) interface supports rendering specific moments. frame_diff produces source/code image pairs and difference scores; check_anim checks the page contract, absence of embedded video/raster images, runtime errors and loop seams. These are project methods and bundled checks, not results reproduced by this collection. Website reconstruction also uses ScrollTrigger and actual button/keyboard interactions rather than merely replaying footage.

The README lists six examples: kinetic type, an eye transition, a festival map, weather radar, a sticker portfolio and a podcast player. It says the source clips were generated with MiniMax H3 Max on fal and rebuilt by Claude Opus 5.5 with this skill, with source clips, HTML and synchronized comparison pages in each directory. These offer public artifacts for concrete reconstruction work, but this collection only read documentation statically; it did not play clips, compare frames, execute scripts or verify interactions. High resolution and small files remain project claims, not benchmarks. REA is not mentioned. The project is not merged with other video-reconstruction tools, and ordinary editing tools in the candidate list are not automatically included.
