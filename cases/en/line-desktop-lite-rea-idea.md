Category: Applications and clients · REA

Stage: Needs verification

On October 16, @zmx asks why nobody has used REA to reverse-engineer a lightweight LINE Desktop. The post contains only this idea: no started investigation, retained or removed feature list, protocol analysis, code or tests. Message synchronization, login, security and interoperability with the official service are not inferred to work. REA is the proposed tool, not an operation already performed.
