# zee-rp: native Axure files for AI agents

Category: Applications and clients · REA
Record date: 2026-10-13
Stage: Needs verification

Axure RP is an interactive-prototyping tool. After a computer-use imitation attempt failed, LilZee studied the .rp binary format and implemented handling for LZ4 manifests, .NET typed data graphs and GUID references, providing a pure JavaScript engine and 42 MCP tools so Claude, Cursor and Codex can directly modify text, interactions and repeater data. In a reply during this review, the author explicitly says REA assisted. The public README reports 225 regression checks and samples saved and reopened in the native app; a screenshot-reconstruction example contains 121 editable widgets. Only macOS/Axure RP 11 is validated; Windows is untested. Structure, loading, preview behavior and native-editing validation are declared separately and do not establish full-format support. This collection did not run it. It is a different project from the earlier Axure reconstruction idea by another author.
