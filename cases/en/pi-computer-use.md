# pi-computer-use: desktop interaction for other models

Category: Applications and clients · REA use unconfirmed
Record date: 2026-10-12

Zane Chee wanted the pi agent to have Codex-style computer control, so he studied Codex Computer Use and released pi-computer-use as open source. The author demonstrates an approach prioritizing the macOS accessibility tree and falling back to vision on supported models, with background mode added in later posts. It is a model-independent computer-control tool, with REA use unconfirmed. The demonstration does not imply background control of every app.
