# GNOME Calculator: a reader's account of LowLevelTV's REA/Claude rebuild

Category: Applications and clients · REA
Record date: 2026-10-19
Stage: Needs verification

At 01:40 Beijing time on October 19, @Eros_B23 (Brian) describes LowLevelTV testing REA with Claude and traditional decompilation tools, reportedly reconstructing a working GNOME Calculator in roughly 28 minutes without original source code. The concrete purpose is testing whether behavior recovered from a compiled calculator can be reimplemented. This is a different target from the existing Windows percentage-rule and Fossify investigations.

Retrieving the original confirmed the respondent and wording, but the linked video was not watched and no rebuilt code, calculation cases or timing record was obtained. Approximately 28 minutes, no source required and working are attributed to this retelling, not proof of complete features, equivalent numerical precision or independent reproduction. The post itself warns that understanding software is not perfect reproduction.
