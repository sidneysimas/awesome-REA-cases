# XGIMI Z7X: a Codex-assisted Mac remote using UDP and Bluetooth wake

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-19
Stage: In progress

An October 19 candidate at 00:24 Beijing time retells Codex UDP research, a Mac remote app and a selection box moving right. Its parent, posted by @aifomo602 at 19:46 on October 18, identifies a home XGIMI Z7X whose remote is often misplaced. Codex was asked to investigate its protocol and build a persistent Mac menu-bar app. On the same Wi-Fi network, a UDP right command reportedly moves the projector's selection; wake instead uses captured Bluetooth advertisements from the official iPhone app, including a device identifier and iBeacon signal.

The author says the Mac initially reported successful sending without waking the projector. An independent native foreground helper reportedly achieved a real wake; silent sending is still being improved. Voice volume control, bedtime shutdown and other home devices are future ideas only. The parent predates this window and supplements attribution and technical context rather than becoming a new candidate. No source, packet capture or independent device test is available. Sending success is not receiving success. This is not merged with the existing infrared-focus investigation; REA use is unconfirmed.
