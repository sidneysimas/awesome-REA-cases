# AMOS Pro: bitplane reports an AI-assisted emulator, online IDE and games library

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-24
Stage: Needs verification

At 17:05:27 Beijing time on October 24, 2026, davidsong (@bitplane) reports building an AMOS Pro emulator with AI assistance, accompanied by a full online IDE and games library. AMOS Pro is an Amiga programming environment; the purpose is bringing old games to the web. His claim that at least three team attempts failed over thirty years because of project size was not independently checked.

The supplementary amos-ts README, last changed September 8, 2026 before this window, identifies a TypeScript reimplementation with an interpreter, loaders and headless runner. Code and AMOS graphics derive from published AMOS-Professional-Official material; everything else was reverse-engineered for compatibility. This is not entirely black-box AI decompilation. The README calls the core language complete but records approximated native-machine behavior and remaining backend boundaries, not cycle-exact emulation. Tests can all pass while the faithfulness gate still fails.

The README lists MIT for the implementation but acknowledges copyrighted works in its online games library under an abandonware assumption. That label is not proof of permission. This collection ran no IDE, game or tests, endorses no distribution rights, and does not turn project completion claims into support for all AMOS games. The specific AI model and REA use are unspecified.
