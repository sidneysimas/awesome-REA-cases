# ArkWeb: a two-game experiment bringing Spider-Man to Gotham

Category: Games and preservation · REA use unconfirmed
Record date: 2026-10-17
Stage: In progress

At 04:04 Beijing time on October 17, @tezzarc introduced ArkWeb through the REA + Opus 5.5 topic. A supplementary check identified the public luki-1/ArkWeb repository. It runs Marvel's Spider-Man Remastered alongside Batman: Arkham Knight, streams Gotham collision into Spider-Man's physics world and composites Spider-Man's rendered frame into Arkham. During combat, an invisible Batman performs the moves while Spider-Man follows the pose each frame. The README explains a guest scene about 2 km above New York, 50 m tiles, skeleton investigation from recorded motion, and agent-guided installation and troubleshooting. This is neither complete decompilation of both games into a new engine nor merely a model replacement.

The October 1 PHASE2 notes document PhysX layouts and geometry exports and explicitly label the Spider-Man runtime-collision implementation at that stage as built but not yet run. The newer README reports end-to-end operation but still calls it experimental, documenting thin-building clipping, collision gaps while areas load, lighting problems and incomplete hand poses in combat. It requires Windows, owned Steam copies of both games and specifically Spider-Man version 4.0630. An October 3 documentation commit credits Claude Opus 5.5 as co-author, supporting AI involvement in documentation and setup, not proof that a model performed all reverse engineering. Project materials do not confirm REA use. October 1–3 materials are out-of-window background evidence; the October 17 post is the candidate. Only documentation, the file tree and commits were read; the mod was not run or independently reproduced.

The project reports experimental end-to-end operation; this collection only read materials and did not run the games or verify performance.
AI setup guidance and documentation collaboration are visible; REA use and attribution of the entire reverse-engineering effort to AI remain unconfirmed.
