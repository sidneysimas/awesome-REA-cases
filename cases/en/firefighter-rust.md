# Firefighter: from DOS binary to Rust

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-12

Firefighter is an old DOS game. Eric S. Raymond wanted to recover program logic from the surviving binary and add it to his collection of old games. According to the author, AI identified Borland Pascal from the data layout, recovered Pascal code with variable and function names, and then rewrote it in Rust. Reverse engineering addresses the problem of having an old executable without maintainable source code. October 5 is the date it was shared; the actual work was completed several months earlier.
