# Civilization DOS 474.05: an account of AI-assisted C reconstruction with four differing bytes

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-20
Stage: Needs verification

At 23:22 Beijing time on October 20, 2026, Xiao Tan (tvytlx) recounts reconstruction of the original 1991 DOS Civilization. Models from OpenAI, Anthropic and Google reportedly recovered C from the binary, then Microsoft C 5.1, MASM 5.10 and LINK 5.01 were used to compare with CIV.EXE version 474.05. The post claims byte identity while also acknowledging four differing bytes, speculatively attributed to an original post-link patch. This record retains the conservative four-byte-difference account, not an identical whole-file hash.

The account explicitly credits prior OpenCiv1 work, acknowledges that its code may be in model training data, and says names, comments and some types are inferred rather than recovered original source. It also claims the developer wrote a technical book about the game's internal systems. The target is readable reconstruction and historical implementation research, distinct from Civilization VI strategy-AI modification.

Reading the thread confirmed the secondary poster's identity. Public searches located existing OpenCiv1 projects but not verifiable source or comparison logs for this 474.05 reconstruction. No compilation, hash comparison or gameplay testing was performed here. The patch explanation and division of model work are unverified; byte matching, the book and involvement of three providers remain source claims. REA is not stated.
