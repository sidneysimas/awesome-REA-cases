# Galaxy-Android: a reported AI-assisted native Super Mario Galaxy port

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-16
Stage: Needs verification

Super Mario Galaxy is a 2007 Wii game. An October 16 post introduces OpenPort Labs' Galaxy-Android as an unofficial native Android ARM64 port based on the Petari decompilation rather than emulation, explicitly crediting AI assistance. It lists stable OpenGL ES 3.2, experimental Vulkan, touch and gamepad controls, Hor+ ultrawide support and Quick Save Anywhere. It targets 1080p/60 FPS and claims good performance even on mid-range Snapdragon devices. The project name, features, same-day release and performance are claims in this post: no repository or device test was obtained, so neither publication nor performance across devices is established. The post calls it an early experimental community project with glitches and requires the user's legally dumped Wii ROM in ISO/RVZ/WBFS format; this collection distributes no game files. REA use is unconfirmed.

October 16 candidate snapshot: 1 like, 47 views; no independent execution or source inspection.
