# Chessmaster 9000: SenG uses Codex to reconstruct The King from x86 into browser Wasm

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-23
Stage: In progress

The candidate posted at 14:33:16 Beijing time on October 23, 2026 is the fourth post in a five-post author thread by SenG (@senguttuvang). Reading the full thread, dated 14:32:16-14:33:25 that day, identifies the target as the chess program Chessmaster 9000. He remembers its 3D boards, pieces and teaching voices from college, followed by years away after moving to the Mac. Inspired by Dhaiwat Pandya's Cricket 07 browser port, he wanted to play it again in a browser. The supplementary parent thread identifies the target and motivation; it is not an additional candidate.

He says Codex helped reverse-engineer the binaries, translating the x86 code of The King chess engine into C and compiling it to WebAssembly. TypeScript and Three.js reconstruct the interface using recovered original boards and pieces. He supplies play and repository short links, describes the repository as source-only reconstruction tools, requires users to supply their own game media and credits Ubisoft and other rights holders. It is an unofficial, unaffiliated project. REA is not mentioned.

This review read only the original post and author thread. It did not resolve the play/repository short links, run the game, compile source or compare engine outputs. Playing strength, move equivalence, restored courses and restored voice instruction are not established. The author's statement that the original engine runs is not upgraded to byte-matching proof. This is an in-progress preservation project with a concrete technical route and an announced playable version; asset rights remain with their owners.
