# An owned robot vacuum: a Claude Code prompt for investigating remote-viewing evidence

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-20
Stage: Needs verification

At 09:21 Beijing time on October 20, @tezzarc publishes a full prompt asking Claude Code to investigate whether a user's own robot vacuum could be watched or listened through remotely. It starts with a photo or About screen to identify manufacturer, model, firmware, OS and camera/microphone hardware; researches public vulnerabilities and manufacturer advisories; checks actual support for video, audio, maps, photos, telemetry and cloud recordings; and guides inspection of the app's shared users, sessions, remote-viewing history and alerts.

For local execution it requires permission before testing and limits investigation to owned network devices. Unexpected logins, unknown sharing and unexplained remote commands are investigation leads; ordinary cloud connections are not evidence of spying. It explicitly excludes rooting, exploitation, authentication bypass and access to other people's devices. Missing manufacturer logs must produce an inconclusive result.

This is a concrete privacy-investigation idea and reusable prompt, not a finding that any model is compromised or secure. No actual model, packet capture, access log or execution report is supplied, and REA use is not stated. This collection did not scan networks, inspect accounts or connect to devices.
