# G-Diffuser: a report of porting an existing F-Zero X decompilation to 3DS with Claude-led agents and 60 FPS

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-27
Stage: Needs verification

At 15:02 Beijing time on October 27, 2026, ProudCat (@ProudCat98) replies to @dizha88 about one person and multiple AIs bringing an old game to 3DS at 60 FPS, asking whether AI mainly read decompiled code or optimized performance. Supplementary lookup of Derek's (@dizha88) original post at 05:02 that day identifies G-Diffuser: a Nintendo 3DS port of the existing decompilation of the 1998 F-Zero X, not proof that AI performed the entire original decompilation.

The upstream account says v1.0.0 supports old and new 3DS, the 64DD expansion's track and vehicle editors, stereoscopic 3D and native rendering. A long-running Claude session reportedly coordinated development; phase one used 147 subagents, 3.17 billion tokens and about $4,974 in API costs over 24 days from a black screen to native 60 FPS on New 3DS. Phase two reportedly spent 43 days addressing the old 3DS's 64 MB memory constraint. All figures are attributed to Derek's retelling, not the project author's sessions, invoices or this collection's measurements. The candidate's question does not itself establish AI's division of work.

No repository, release record, build logs, frame-time data or hardware comparison was obtained. Stable 60 FPS throughout, complete editor compatibility and individual agent contributions are not confirmed. Included as an unverified, concrete AI-assisted porting report, without a REA mention, game downloads, execution or independent reproduction.
