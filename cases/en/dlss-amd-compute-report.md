# DLSS on AMD: reported AI-assisted compute-shader reconstruction

Category: Algorithms and feature recovery · REA use unconfirmed
Record date: 2026-10-12
Stage: Needs verification

DLSS is NVIDIA's game-image reconstruction technology. In a related thread, MisterSpace3 claims AI reverse-engineered and reimplemented it to run as ordinary compute shaders on AMD GPUs. The background DLSSNR-AMD repository does publish a Vulkan implementation, reports testing only on an RX 9070 XT, labels Windows an experimental preview and does not distribute original model weights. However, this review did not establish that the comment refers to that exact repository, and its README does not describe AI development contributions. This remains an unverified report with a concrete interoperability purpose, without crediting all public results to AI.
