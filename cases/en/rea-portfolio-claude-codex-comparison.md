# Paid portfolio animations: same-prompt REA rebuilding with Claude Code and Codex

Category: Applications and clients · REA

They give Claude Code and Codex the same prompt: use REA to investigate a reference URL's animations/interactions with evidence, then build an original portfolio using only the author's real content and photo. Reference and two result short links are provided, but expanded sites, code and behavior tests were not obtained. Percentages are subscription-session consumption, not equal token counts, API bills or controlled costs. Better visuals from the slower model is the author's judgment.
