# Radian Browser: studying Arc gestures and UI with Claude and REA on top of Orbe

Category: Applications and clients · REA
Record date: 2026-10-24
Stage: In progress

At 23:57:01 Beijing time on October 23, 2026, Abdullah Sultan (@amsultan2010) introduces Radian Browser, a macOS/Electron beta intended to preserve Arc's Spaces, Command Bar and vertical tabs, with reported Arc settings import. His reply at 23:54:26 says Claude used REA and Hopper to analyze Arc on his Mac, making gestures straightforward. Both posts belong to this target rather than separate gesture and browser cases.

The public README adds important attribution and methodological limits: Radian is an early fork of MIT-licensed Orbe, which supplies most existing functionality. Radian's own work includes English menus, branding and remeasuring Arc 1.170 layouts, colors and motion. The README says behavior is matched by observing the running app frame by frame, without reading Arc code or reusing assets. The relationship between that statement and the author's Hopper-analysis reply is unexplained. This is not a verified clean-room assurance, nor evidence that AI recovered every browser feature from scratch.

The README requires macOS 13 or later, initially Apple Silicon, with no Intel build and releases not yet notarized by Apple. Accounts, sync and AI features are currently absent. The post names sync, MCP and mobile as future directions, not delivered functionality. Lightweight operation, battery efficiency, complete Arc equivalence and Arc shutdown dates remain author or project statements, not independently endorsed here.
