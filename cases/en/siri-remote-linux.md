# Siri Remote on Linux

Category: Hardware and interoperability · REA use unconfirmed
Record date: 2026-10-12

The first-generation Siri Remote was designed specifically for Apple TV. Alex Funk reverse-engineered its Bluetooth protocol so Linux could interpret data from the remote without going through an Apple TV. The author says this took about 45 minutes and released an open-source implementation; demonstrations cover touch, buttons, gestures and the microphone. The concrete result connects an input accessory originally intended for a closed device to the author's own computer. The original post does not explicitly say whether REA was used.
