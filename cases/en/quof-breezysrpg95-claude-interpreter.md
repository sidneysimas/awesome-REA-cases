# BreezySRPG95: Quof uses Claude to disassemble an old runtime and build a replacement SRPG client

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-25
Stage: In progress

At 12:56:56 Beijing time on October 25, 2026, Quof (@Mr_Quof) said he referenced the REA repository and used Claude Code CLI to disassemble the original executable and code a client. Reading the 12:56:55 parent identified BreezySRPG, a replacement player for tactical games made with Sim RPG Maker 95 (シミュレーションRPGツクール95). Placing the player in a legally obtained game's directory aims to improve the experience of running old games on modern computers. Referencing REA does not establish that its MCP server was actually connected.

In the same thread, Quof lists keyboard controls, fast-forward, skipping enemy turns, high-resolution display, borderless windows, saving during events and enemy movement ranges, explicitly calling it an early beta tried by only a few people. Supplementary reading on October 26 found the public Quof/BreezySRPG95 repository. Its README, pinned to October 25 commit cad576ddcec2ea92ef6e3a82bb40068b096c8ba4, says it never modifies game files and lists えるまに, ＯtoＺ, 昴の騎士 and both parts of 闇鍋企画 as tested games. It also limits original-player save compatibility to slots 1-8: slots 9-100 are replacement-client-only, and loading a cutscene save in the original returns to the turn menu.

The parent and repository supply target identity and compatibility context for the candidate's method statement; they are not additional candidates. No release was downloaded and no game or decompilation quality was tested here. Features and tested games are author/project reports, not a guarantee of compatibility with all SRPG Maker 95 games or proof of recovered original source.

Early beta tried by only a few people; not independently run.
Referencing REA does not confirm its use; save compatibility has slot and event-state limits.
