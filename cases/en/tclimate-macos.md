# TCL air conditioners: a reported macOS control app

Category: Hardware and interoperability · REA use unconfirmed

TCLimate is a native macOS menu-bar controller for TCL air conditioners. A post says a developer used REA and mitmproxy to reverse-engineer the TCL Home iOS app, then built an open-source tool for click-based air-conditioner control without a remote or phone.
