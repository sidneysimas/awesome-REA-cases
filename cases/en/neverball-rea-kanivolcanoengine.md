# Neverball in KaniVolcanoEngine: REA extracts a specification, an LLM rebuilds in Rust

Category: Games and preservation · REA

Stage: Needs verification

At 22:47 Beijing time on October 21, 2026, Otinpan (@otinpan512) describes combining REA with KaniVolcanoEngine. REA first investigates Neverball's executable and generates a specification covering game logic and level structure. An LLM then uses that specification to recreate the game in the author's custom Rust game engine, KaniVolcanoEngine. The reported route is executable to specification to another engine, not merely copying a screenshot's interface.
