# Reall: Conra's explainable five-phase interface for a REA fork

Category: Applications and clients · REA
Record date: 2026-10-29
Stage: In progress

At 11:30:51 Beijing time on October 29, 2026, Conra (@Conra22a) introduces Reall as a self-built REA fork intended to reduce terminal dependence and blind trust in a model. The listed target types are web apps, JavaScript/Electron, Android and native binaries. Model options include OpenAI, Anthropic, Gemini, OpenRouter, Ollama and compatible local models.

In his description, users create projects and choose local output folders, follow analysis, specification, build, verification and reporting phases, and scope reconstruction to an entire application, a module or a feature. They may request improvements, optimization or language/framework migration. The interface can configure credentials or cookies required for target authentication, show live activity, tokens and estimated costs, and set per-run budgets. Its claimed value is explaining what AI is doing, the evidence it uses and what remains unverified, not reporting a completed target reconstruction.

Lookup confirms attribution. The candidate provides no repository, executable revision, audit or end-to-end acceptance result. Supported targets and cost displays remain author claims, not guarantees of universal compatibility, accurate costs, credential safety or sufficient automated verification. No credentials were read and the tool was not run here. This is separate from the same author's Point Smart device research.
