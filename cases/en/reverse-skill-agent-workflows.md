# reverse-skill: investigation workflows for coding agents

Category: Applications and clients · REA use unconfirmed
Record date: 2026-10-15
Stage: Related project

This window introduces reverse-skill, reportedly usable in Codex, Cursor and Claude Code to select tools and investigative steps for APKs, frontend code and firmware. Its purpose is reverse-engineering guidance and tool orchestration for agents, not a new decompilation engine. The candidate gives no directly checkable repository address, sample or acceptance log. Claims that it knows how to take things apart do not establish reliable handling of every format. It is included as a related workflow project. Its name differs from apk-reverse, with no evidence that they are the same project, and an REA foundation is unconfirmed.

Feature scope is post-described, not independently checked.
