# Bluetooth gamepad on Windows

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-12

MonoFevc bought a Bluetooth controller advertised as not supporting Windows and wanted to play mobile games on a PC. The author reports reverse-engineering its control protocol and writing a ViGEm driver with AI-assisted development to make relevant controller functions work. ViGEm emulates controller input recognized by Windows games. The post supplies no model, driver source or test details, so the result is treated as a firsthand account.
