# Project Midas: a Claude-assisted GoldenEye PC port built on existing N64 decompilation

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-23
Stage: In progress

The older candidate was posted at 09:04:22 Beijing time on October 18, 2026. Responding to a retro-game decompilation discussion, Graslu00 describes two programmers using AI assistance, with dedicated players and modders testing intensively. A supplementary reply at 14:32:01 that day explicitly calls the project Project Midas. These are community explanations, not this collection's validation of testing quality or labor.

The subsequently located public murkantor/Project-Midas README identifies a work-in-progress GoldenEye (GE) PC port built on the existing N64 decompilation, targeting Windows and Linux and reading game data from the user's own US cartridge image. It explicitly acknowledges Claude's involvement and credits prior work including n64decomp/007. Porting is not presented as AI single-handedly performing the original decompilation, recovering original source or eliminating human effort. The README does not identify Claude's functions, model version or any REA use.

Supplementary material retrieved outside the window is pinned to 4b5ca71e93554d6a86b5d08a0ef1bea3fc0258a7, dated 2026-10-22T20:15:25Z, after the candidate. Its features cannot be backdated to October 18. This revision still lists co-op, netplay and mod loading as in progress, with the ordinary build loading only the stock cartridge. It documents a Linux issue where levels render as large blank triangles on some systems. MIT applies only to the port code, not decompiled game code or assets.

This collection read public documentation only, obtaining no cartridge and performing no build, execution, playback verification or independent retest. Community praise for testing and the README's running instructions retain separate attribution. The status remains in progress, not guaranteed compatibility or a completed release.
