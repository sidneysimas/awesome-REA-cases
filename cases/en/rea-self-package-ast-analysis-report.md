# REA analyzes its own package: reported AST scale, evidence size and an 8 KB fork

Category: Applications and clients · REA
Record date: 2026-10-19
Stage: Analysis test

At 02:06 Beijing time on October 19, a post says REA was pointed at its own package and one command analyzed 1,706 files and 3,315,012 AST nodes in 289 seconds, producing 234 MB of evidence JSON. An AST is an abstract syntax tree representing code structure; these counts do not mean an equal number of recovered features or a successful software rebuild.

A 02:07 follow-up says an article contains measurements, installation limits, an evidence record requiring blind spots to be named, and an 8 KB fork that matched it. The article, sample version, machine, command, evidence JSON and comparison criteria were not obtained. An 8 KB implementation is therefore not established as equivalent to REA, nor guessed to be the existing LeanREA project. Star counts are attributed background, not current repository engagement or effectiveness evidence. No target was run or independently timed.
