# Home-device protocols connected to a local LLM

Category: Hardware and interoperability · REA
Record date: 2026-10-15
Stage: Needs verification

DiscusFish (@bitfish) finds that purchased smart-home devices remain fragmented by their separate remotes. In an October 15 post, the author describes integrating them by calling APIs directly where available, or using REA to decompile apps and discover protocols where no API exists, then connecting everything to a local LLM for orchestration. The goal is a unified software-control entry point for personally owned home devices. The original post supplies no models, protocol details, source or per-device test results. This is an author-reported integration, not evidence that all devices support local offline control, and is separate from other authors' whole-home projects.
