# Decompwtf: agents reconstruct game C/C++ and compare machine code

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-16
Stage: Related project

On October 16, @Pirat_Nation introduced Decompwtf as a project that lets AI coding agents reconstruct C/C++ from compiled game code, then compile it and compare machine code with the original binary to accelerate game preservation and existing community decompilation work rather than merely redraw interfaces. The post lists N64, PS1, PS2, GameCube, Wii, GBA and DS targets and says it runs locally without an account or game-data uploads. These are the source's descriptions of workflow and scope, not evidence that arbitrary games have reached byte matching. Public GitHub repository-name searches did not yield confirmed source, matching logs or a completed-game list. Open-source, privacy and compatibility statements remain attributed claims; this collection did not install or run it.

A new third-party account at 21:19 Beijing time on October 16 says the author stopped updates because of opposition from decompilation communities. Reading the original introduction's conversation also found @nycfurby saying at 09:26 that day that the project was discontinued and attributing this to community resistance. These are third-party claims about maintenance and motivation, not a verified author announcement, and do not mean the entire decompilation community closed. A later reply about one-person maintenance, Claude Code debugging and rollback does not name its game and cannot establish a Decompwtf result or completed-game list. Neither the alleged reason for discontinuation nor functional availability was confirmed here.

October 16 candidate snapshot: 1,331 likes, 30,869 views, 116 reposts; engagement is not validation.
