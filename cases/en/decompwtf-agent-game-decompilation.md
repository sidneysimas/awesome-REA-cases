# Decompwtf: agents reconstruct game C/C++ and compare machine code

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-16
Stage: Related project

On October 16, @Pirat_Nation introduced Decompwtf as a project that lets AI coding agents reconstruct C/C++ from compiled game code, then compile it and compare machine code with the original binary to accelerate game preservation and existing community decompilation work rather than merely redraw interfaces. The post lists N64, PS1, PS2, GameCube, Wii, GBA and DS targets and says it runs locally without an account or game-data uploads. These are the source's descriptions of workflow and scope, not evidence that arbitrary games have reached byte matching. Reading the thread and searching public GitHub repository names did not yield confirmed source, matching logs or a completed-game list in this review. Open-source, privacy and compatibility statements remain attributed claims; this collection did not install or run it.

October 16 candidate snapshot: 1,331 likes, 30,869 views, 116 reposts; engagement is not validation.
