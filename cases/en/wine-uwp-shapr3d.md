# wine-uwp: Windows Store apps and Shapr3D on Linux

Category: Applications and clients · Other AI-assisted work
Record date: 2026-10-12
Stage: Needs verification

Wine is a compatibility layer for running Windows software on Linux. UWP/MSIX store apps additionally require the package model, WinRT and UI-composition interfaces. DesignGears reports creating wine-uwp with Claude doing most reverse engineering and coding while the author directed and tested. The original post and README list Shapr3D, Solitaire, Media Player and Calculator. A later post in the same review introduces Shapr3D for Linux based on this runtime, claiming modeling, login, cloud sync and STL/PDF export work, while remaining an unofficial beta. The project runs Microsoft's existing UI framework rather than rewriting all of Shapr3D or Windows. This collection checked public material only and did not run the apps.
