# IsaacRecomp: the Flash Binding of Isaac as native C++

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-15
Stage: In progress

The original 2011 Binding of Isaac depends on Flash, with low-resolution graphics and logic at about 30 Hz. The candidate recounts IsaacRecomp becoming a 1440p, 165 FPS C++ port in days. Reading whylurking/IsaacRecomp's public README on October 15 confirmed the author's explicit acknowledgment of AI help and description of translating the original game code to C++, reading images and audio from the user's own Steam Isaac.exe, preserving 30 Hz logic and interpolating rendering for higher refresh rates. It lists PC, Android and Switch homebrew versions. This collection did not run the game; the candidate's effort and 165 FPS are not measurements here, and a cross-platform download table does not establish validation on every device. Lawful ownership of the original is required; REA involvement is unconfirmed.

Public project documentation adds evidence of AI involvement; performance not independently retested.
