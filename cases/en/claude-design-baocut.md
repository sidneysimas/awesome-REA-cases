# Claude Design in BaoCut

Category: Applications and clients · REA use unconfirmed
Record date: 2026-10-12

BaoCut began as 宝玉's video-editing agent. After researching Claude Design, the author integrated a design skill and frontend features into BaoCut so local agent CLIs could select the design skill, with public code commits. The author notes that a standalone skill cannot support editing, modification and annotation, so integration into the product came first. The post does not explicitly establish REA use in this work or full recovery of the original product's capabilities.

A third-party repost on 2026-10-13 says REA MCP helped break down Claude Design's obfuscated code before Claude Code rewrote it, and that Design and Slides were integrated into open-source BaoCut. It also recounts the idea of using Slides to generate a skill with similar results. This is not direct confirmation by the original author. The account and implementation were not verified in this review, so it does not change confirmation of REA use or establish a complete Claude Design copy.
