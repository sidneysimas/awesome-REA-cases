# AirDrop-like Mac/Windows transfers: an Opus Electron app, not proof of Apple-protocol compatibility

Category: Applications and clients · Other AI-assisted work
Record date: 2026-10-28
Stage: Needs verification

At 01:14:27 Beijing time on October 28, 2026, an author claims to have reverse-engineered Apple AirDrop with Opus 5.5 for direct Mac/Windows file transfer without cloud services, accounts or cables. The visible steps instead describe Claude Code choosing Electron in an empty directory, UDP discovery broadcasts every 1.5 seconds, direct file streams and Accept/Decline controls with an always-accept option for one's own devices. The concrete purpose is cross-platform local sharing; the headline does not establish interoperability with system AirDrop.

The author reports an initial byte-for-byte folder/3 MB transfer test between two fake devices; separate agents building iOS 17 NameDrop-like WebGL glow, icons and a site; review finding a Mac black-screen shader issue; and GitHub Actions packaging DMG/EXE files. The first Mac launch only bounced the dock icon; startup logging and forced window opening reportedly fixed the next build. One afternoon, zero hand-written lines and successful transfers are author statements. Repository, test records and packages were not obtained. Recovery of Apple's discovery/encryption protocols and safety of always-accept were not established. Included as a functional-experience reconstruction report, without running the app.
