# Old game saves in the browser: a REA rules-and-progress migration idea

Category: Games and preservation · REA
Record date: 2026-10-18
Stage: Needs verification

At 02:38 Beijing time on October 18, 2026, @mika_systems proposes using Claude Code and REA to continue an unfinished old game from its save in a browser rebuild. This is not a completed port: level 7 and three keys illustrate preserving level and inventory state. Users would need original game files, reusable assets and a save copy, first running the original in a compatible environment and recording a complete level before investigating missing movement, checkpoint and save rules.

The proposal separates investigation, browser implementation, old-save-field mapping and comparative review, using identical states and recorded inputs. Its acceptance sequence is loading the old save, completing a level, saving, closing the browser, reopening and continuing, then retesting exported-save import in a clean session. It asks users to preserve originals and record unmappable fields, missing assets and unsupported formats. No game, importer code or passed test is supplied; this is a concrete workflow idea, not demonstrated save compatibility.

Source: October 18, 2026, 02:38 Beijing time; level 7/three keys is an example, without game or test artifacts.
