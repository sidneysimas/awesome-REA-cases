# Universal Modder: AI-assisted game mods

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-19

Rehan Sheikh turned the process of modifying games into Universal Modder. Mods add characters, mechanics or content to existing games rather than developing an entire game anew. The author has Claude analyze game engines, code and file formats, then generate assets, modify content and test it in the game. Demonstrations include adding a Robotaxi civilization to Age of Empires II and placing Minecraft characters and scenery in GTA V. The goal is for an agent to connect game-modding steps that previously required multiple tools; this does not mean all these games have been fully decompiled.

At 20:46 Beijing time on October 19, a separate circulating post claims Opus 5.5 and REA put Fortnite inside Minecraft and Minecraft inside GTA 5, describing Fortnite build pieces and a weapon bar over Los Santos streets. It narrates routing Windows programs through Ghidra, reading Java bytecode or rebuilding from rules, searching glide/build/storm clues, observing 60 seconds of gameplay, writing SPEC.md with 14 storm rules, then rebuilding and comparing. This supplements the same kind of cross-game target but is not confirmed as a Universal Modder release, the same author or the same implementation. No code, function addresses, rule specifications or test records are available, and this collection did not watch the full demonstration. Sixty seconds, fourteen rules and feature matching are not independently validated, nor is complete Fortnite decompilation established. The original project retains its other-AI classification; REA appears only in the added promotion.

Original project's engagement snapshot (2026-10-12): 14,340 likes, 3,822,000 views and 896 reposts.
Original project posted September 30 and its original source is not REA. The separate October 19 promotion has 10 likes, 367 views and 0 reposts; these are not the same circulation statistics.
The October 20, 15:00 candidate names rehan-remade/universal-modder, claiming 11 skills, um CLI and fal MCP span reconnaissance, assets, testing and publication. It describes over 20 engine playbooks and um scan identifying versions, native versus .NET, anti-cheat and loaders; only game-worker touches a running game, while the orchestrator plans/checks and offline-worker researches offline. Publication checks reportedly block game files, decompiled code and keys. This is a third-party introduction, not a full repository review or executed checks; neither testing of every engine nor absence of secret leakage is guaranteed. Its 8,344-star figure is a third-party snapshot; the candidate itself has 0 likes and 17 views.
