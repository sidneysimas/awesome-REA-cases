# Universal Modder: AI-assisted game mods

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-12

Rehan Sheikh turned the process of modifying games into Universal Modder. Mods add characters, mechanics or content to existing games rather than developing an entire game anew. The author has Claude analyze game engines, code and file formats, then generate assets, modify content and test it in the game. Demonstrations include adding a Robotaxi civilization to Age of Empires II and placing Minecraft characters and scenery in GTA V. The goal is for an agent to connect game-modding steps that previously required multiple tools; this does not mean all these games have been fully decompiled.
