# Dell displays: a Claude-assisted macOS menu-bar app for PiP/PbP

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-19
Stage: Needs verification

At 12:49 Beijing time on October 19, @codeandrewford reports in an AI software-replacement discussion that Dell's display manager was unavailable for their newer macOS version. Claude investigated screen control, and they now have a menu-bar app controlling PiP/PbP: picture-in-picture and side-by-side pictures. The purpose is restoring display controls no longer provided by the proprietary manager, not rewriting monitor firmware.

Reading the conversation confirmed attribution, but no display model, macOS version, DDC/CI or other protocol, source or command-response logs are supplied. Working PiP/PbP remains an author report; support for all Dell displays, automatic multi-input switching and arbitrary display features are not inferred. REA use is unconfirmed. No device was connected or app independently run here, and this is separate from the LG UltraFine updater patch.
