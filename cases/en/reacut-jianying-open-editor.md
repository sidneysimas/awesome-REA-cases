# ReaCut: an independent editor informed by Jianying research

Category: Applications and clients · REA
Record date: 2026-10-15
Stage: In progress

Previously, @zoozoo_ai said they were reverse-engineering Jianying with REA, invited contributors and linked Xiangyu-CAS/rea-capcut. This is separate from Mehal's existing CapCut editor. On October 15, repository research and validation documents from October 13 were checked: the author used REA 6.4.0 to inspect macOS Jianying 11.0.12922, passively observe new-project creation and timelines with self-made assets, and distinguish component/string presence from actual behavior. The initial opaque draft cannot directly establish format support. The independent implementation uses its own project format and FFmpeg exports; commercial assets, original binaries and a complete native call graph are not presented as recovered results. Validation records report 293 passes and one skip for missing libx265, plus actual installed-package exports of videos with Chinese text and mixed audio and plugin-protocol tests in an isolated environment. The user confirmed Codex sidebar visibility, but complete host workflows, cross-platform support and initial CI failure retain limitations. Version 0.5.0 is an Apple Silicon preview package with only local ad-hoc signing and no notarization. This collection only read project records; author acceptance is not independent reproduction or all-green cross-platform CI.

At 16:32 and 16:41 Beijing time on October 16, two candidate replies from the same @zoozoo_ai account add that the editor itself is the smaller problem: licensed assets and AI APIs are the bottleneck and the workload remains large. This is a specific account of project gaps, not acceptance of a new release. Both replies use the same short link, so no separate case is created, and restored commercial-asset permissions or cloud AI services are not inferred.

Earlier candidate is a work-in-progress invitation; October 13 documents are retrospective supporting evidence, not newly completed results in this window.
Two same-account replies on 2026-10-16 confirm asset and AI API gaps; not independent acceptance or acquisition of commercial resources.
