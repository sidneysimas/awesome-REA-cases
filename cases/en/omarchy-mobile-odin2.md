# AYN Odin 2 Portal: Codex-assisted native Omarchy bring-up

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-13
Stage: In progress

The author reports working with Codex on native Linux bring-up for the AYN Odin 2 Portal: first inspecting the actual device, saving base-system backups and hashes, then studying UFS partitions and the boot chain to install Arch Linux ARM/Omarchy rather than a VM inside Android. The report covers AVB metadata, a boot-partition failure caused by 4,096-byte logical sectors and recovery validation. The goal is a touchscreen desktop, controller shortcuts and a local game library. The public omarchy-mobile-odin2 README matches the original target and records boot, display, touch and Wi-Fi working. These remain author/repository claims; this collection did not handle the device. Microphone voice capture, cold boot, alternate-slot recovery and other hardware acceptance checks remain incomplete, and backup restoration itself was not tested. Upstream Linux, ROCKNIX and others supplied substantial foundations; this is not AI reconstruction from scratch. REA use is unconfirmed.
