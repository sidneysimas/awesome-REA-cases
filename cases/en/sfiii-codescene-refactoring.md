# Street Fighter III: AI refactoring of decompiled C

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-12
Stage: Related project

A post in this review recounts CodeScene's refactoring study of open-source decompiled Street Fighter III: 3rd Strike code. The goal was to improve maintainability of about 300,000 lines of C, primarily using Claude Code / Opus with CodeHealth MCP scores and frame-by-frame replay-state hash checks for behavior. The report claims three weeks, about $4,000 in token costs, a score increase from 5.6 to 10.0 and 54 PRs merged into the main branch of a fork. This is neither AI decompiling the game from scratch nor changes already merged upstream. Performance, architectural quality and nonfunctional regressions remain research questions; predicted reductions in defects are not measurements from this work.
