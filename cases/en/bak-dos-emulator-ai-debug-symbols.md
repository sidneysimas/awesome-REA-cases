# A DOS emulator from BaK research: AI-driven debugging, with C-level symbols unfinished

Category: Games and preservation · REA use unconfirmed
Record date: 2026-10-21
Stage: In progress

At 21:02 Beijing time on October 21, 2026, Cesar Canassa (@ccanassa) presents a DOS emulator written during BaK decompilation and says it can be fully AI-driven. He is adding Borland debug-symbol support so agents can step through C rather than assembly, explicitly stating that this part is unfinished. The goal is better debugging feedback for old DOS-program research, not complete BaK source recovery or an agent independently finishing the game.

The original post confirmed authorship and the unfinished state, but the short-linked project, emulation accuracy, instruction coverage, debugging API and tests were not obtained. BaK remains the author's abbreviation rather than an inferred game identity. AI-driven operation and C-level debugging have different reported maturity; the latter is not described as available. REA is unconfirmed, and neither emulator nor target was run here.
