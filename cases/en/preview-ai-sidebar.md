# Apple Preview: adding AI directly to a compiled app

Category: Applications and clients · REA use unconfirmed
Record date: 2026-10-12
Stage: Needs verification

Zhuo Zhang's team uses macOS Preview, the image and PDF viewer, to demonstrate OmniSE: developing from existing software rather than only source code. The author says Astra Max added AI features to the app in under 20 minutes. The corresponding Edit My App repository uses adding an AI sidebar to Preview as an example and describes copying the original app before modification and testing. The project reports only the macOS route as validated, and generated apps remain personal experiments. This collection read only public posts and the README and did not run the modified app; REA use is unconfirmed.
