# A 2014 Samsung TV: Claude investigates an encrypted remote protocol and pairs by PIN

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-19
Stage: Needs verification

At 11:13 Beijing time on October 19, tezarc (@tezzarc) reports giving Claude Opus 5.5 and Claude Code control of a 12-year-old non-Android Samsung TV from 2014. The stated working steps are discovering the television on the local network, figuring out its encrypted remote protocol, pairing with the PIN displayed on the TV and sending real remote commands. The purpose is using natural-language requests instead of a handheld remote to keep old hardware useful.

The author explicitly says no firmware hacks were involved. Retrieving the original confirmed attribution and a video attachment, but this collection did not watch the video or test commands. 'Doing ANYTHING' is not expanded into arbitrary-app control, flashing or compatibility with every TV. No exact model, protocol implementation, code, pairing log or response comparison was obtained, and REA use is unconfirmed. This is not merged with Aswin DG's web remote for another Samsung TV; the two authors' actions are not independent reproductions of one implementation.
