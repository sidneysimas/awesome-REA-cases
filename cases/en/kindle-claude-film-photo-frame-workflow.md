# Kindle film-photo frame: a Claude Code workflow for USB, images and FBInk

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-21
Stage: Needs verification

At 03:49 Beijing time on October 21, 2026, an author shares a detailed prompt incorporating lessons from their Claude session: turn an Amazon Kindle into an e-ink frame for scanned film, have the computer handle files while the owner presses device buttons, and minimize USB-copy sessions. USB information, serial prefix and system version select an existing jailbreak; stop if unsupported, without deregistration or factory reset.

Image requirements include panel-resolution grayscale, light sharpening, a contact sheet and skipping blank frames. The proposed app changes photos every 30 minutes, shuffles without repeats and saves position. Tapping reveals a clock and Open-Meteo weather; swipes, long-press exit, 16-gray dithering and FBInk partial updates are specified. It also calls for restoring the stock UI, hardware dark-mode handling, RTC wake and power-saving fallbacks, and a preview GIF before device execution.

These are requested acceptance conditions, not device results inspected here. The author flags different choices for 11th-generation-and-later MTP devices and firmware 5.16.3 or later. No model, source, GIF or flashing log is supplied. Reusing community jailbreak/display tools does not mean Claude discovered a vulnerability, and REA participation is unconfirmed.
