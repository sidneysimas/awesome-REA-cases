# RE-Agent: legacy Project I.G.I. 2 GConv/QVM tooling

Category: Games and preservation · REA
Record date: 2026-10-16
Stage: In progress

Haseeb Mir (@HaseebMir91) introduces RE-Agent, an REA fork for troubleshooting unsupported older software and games, with the GConv/QVM tools for 2003's Project I.G.I. 2 as its first concrete case. The described workflow reproduces faults, collects static and runtime evidence with Ghidra/IDA/Hopper and Frida, fixes them in a separate workspace, compares originals and repaired versions, and outputs pass, mismatch or unknown. A later post adds headless Ghidra analysis, an IDA bridge and memory tracing. Candidates provide no specific fault, patch, input sample or passing record. This collection confirmed the original poster but did not locate a repository or tests. This is a project direction and ongoing target, not a fix for all IGI tools or a general guarantee against hallucinations.

October 15 author report; patch or actual validation output not obtained.
