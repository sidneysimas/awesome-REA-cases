# Oblivion browser engine: reported REA notes to TypeScript and Three.js

Category: Games and preservation · REA
Record date: 2026-10-21
Stage: Needs verification

At 03:23 Beijing time on October 21, 2026, an author describes an educational project: Claude used REA to decompile The Elder Scrolls IV: Oblivion, took detailed notes, then wrote a new engine in TypeScript and Three.js from those notes. The purpose is browser execution of the original game, alongside educational material Claude produced during the investigation.

The author claims a from-scratch implementation with adapted original assets streamed from the player's own copy, and reports seeing something that looks like a complete game. No repository, build, mechanic-coverage record or behavioral comparison is supplied. Full playability, source isolation and asset handling are not established. The author explicitly credits paid Claude work rather than personal hand coding. This is distinct from the Oblivion Remastered performance patch; this collection did not run the game or independently reproduce the result.
