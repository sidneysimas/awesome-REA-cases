# Switch Diablo II on Apple devices: an AI-assisted port claim

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-15
Stage: Needs verification

A third-party post in this window says an unofficial project brought the Switch version of Diablo II to iPhone, iPad and Apple Silicon Macs, citing AI-assisted reverse engineering, code adaptation and debugging as background. It explains that Switch and these devices share ARM architecture, potentially reducing some cross-architecture obstacles, but supplies no project name, code, build or compatibility records. Shared architecture does not establish full compatibility, and the exact game version and AI contribution share are unconfirmed. This is a circulating report with a concrete target, kept unverified and separate from the existing Link's Awakening project.

Secondhand account, not author confirmation or execution verification by this collection.
