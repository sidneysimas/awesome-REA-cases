# Cameo: reconstructing desktop-character behavior

Category: Applications and clients · REA
Record date: 2026-10-12
Stage: Needs verification

Cameo is a macOS status-bar app that displays draggable small animals on the desktop using transparent videos or animated characters. wquguru links the original project's release and describes first having Grok Build install REA to obtain pseudocode, then using Claude Code with the compiled application image to recover functionality. The background post being replied to says six subagents recovered the app in an hour, with cat animation matching frame for frame and byte for byte. No reconstruction source or comparison tests are published, so the results are treated as author claims. The original image and character assets were not downloaded.
