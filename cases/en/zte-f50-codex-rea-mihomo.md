# ZTE F50: a reported Codex/REA root and mihomo installation

Category: Hardware and interoperability · REA
Record date: 2026-10-21
Stage: Needs verification

At 11:54 Beijing time on October 21, 2026, Penn (bubbleinpit) says they bought a ZTE F50, immediately rooted its Android system using Codex and REA, and installed mihomo with good results. The purpose is running a personal network proxy on a small cellular device, not an already completed OpenWrt port.

The author says the F50 requires a SIM and cannot relay existing Wi-Fi, and considers OpenWrt flashing possible but unnecessary once root permits mihomo. These are the author's device and alternative-path assessments, not independently verified limitations across revisions or successful OpenWrt installation. No firmware, exploit, privilege-acquisition steps, code, traffic tests or recovery record is supplied. This collection did not connect to or root a device or run a proxy and does not guarantee compatibility or safety.
