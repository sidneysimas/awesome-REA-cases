# OrcaCyber Nano 1.0: a 27B local security model for disassembly interpretation

Category: Applications and clients · Other AI-assisted work
Record date: 2026-10-19
Stage: Related project

An October 19 post at 04:13 Beijing time, explicitly labeled a ChatGPT summary, introduces OrcaRouter's OrcaCyber Nano 1.0: a 27B Qwen3_5ForConditionalGeneration-based model in GGUF for local llama.cpp inference. Its proposed purpose is analyzing sensitive source, logs, disassembly and Ghidra/IDA screens locally instead of sending them to a cloud service. The summary claims a 262,144-token context, image/video support, MTP/DFlash2 speculative decoding, roughly 13 GB and 15.7 GB variants and suggested configurations with 16 GB and at least 24 GB VRAM.

This is a named related-project introduction, not an executed target investigation. The summary repeats MATH-500 98.60%, AIME 2025 96.23% and MBPP+ 84.66%, while explicitly saying evaluation methodology is still being prepared. These are not security or reversing benchmarks. The original article date is absent; the summary date is not a model-release date. No model card, license text or target tests were obtained. Hugging Face access reportedly requires login and consent, which does not establish fully offline operation, commercial permission or absence of data transmission. No model was downloaded or inference run here.
