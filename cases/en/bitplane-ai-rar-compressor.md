# A free-software RAR compressor: bitplane reports AI-assisted support from version 1.4 onward

Category: Algorithms and feature recovery · Other AI-assisted work
Record date: 2026-10-24
Stage: Needs verification

At 17:05:27 Beijing time on October 24, 2026, davidsong (@bitplane) lists a free-software compressor reportedly supporting every RAR version since 1.4 among his AI-assisted achievements. The target is writing an existing compression format, not merely reading old archives. His claim that a small team would otherwise need several years is a counterfactual estimate, not measured time saved.

Searching his public GitHub identifies rars. Its supplementary README, last changed October 21, 2026 before this window, describes Rust compression, decompression and recovery for the archive types the author could find, from early RE~^ archives through RAR 7, with a CLI and Python/TypeScript bindings. It explicitly originated as an agentic development experiment. The document also admits slower execution, more memory and slightly worse compression than WinRAR, with more volume testing needed, and lists Apache 2.0. The post's every-version wording must not erase these limits.

No specific model or REA use is named. This was static documentation reading, not a complete code or license-compliance audit, execution or interoperability test. Coverage, integrity and performance remain project reports, not independent verification or recovery of commercial source.

Every version from RAR 1.4 onward is the author's claim; the README admits performance and volume-testing limits. Compatibility tests were not run.
