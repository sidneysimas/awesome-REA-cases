# HarmonyOS packages: mapping components

Category: Applications and clients · REA
Record date: 2026-10-12

HAP is a HarmonyOS app installation format. A contributor used the real harmony-next-pipeline 1.0.1 open-source release package to verify REA's recognition of HAP, HSP and App Pack, listing component paths, content hashes and runtime clues and comparing CLI and MCP results. The aim is to establish what is in a package and where further analysis could begin. Ark bytecode was not decoded, signatures were not validated, and application runtime behavior was not established.
