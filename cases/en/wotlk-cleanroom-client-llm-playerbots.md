# A cleanroom WoW WotLK client for Azerothcore and LLM player agents

Category: Games and preservation · REA use unconfirmed
Record date: 2026-10-21
Stage: In progress

At 08:45 Beijing time on October 21, 2026, Shannon Sands (max_paperclips) says they are cleanroom reverse-engineering and reimplementing WoW's WotLK (Wrath of the Lich King) client, reporting compatibility with the latest Azerothcore. Existing servers and traditional playerbot mods provide a foundation, but an open, hackable client is wanted for full LLM agents that team with humans, form guilds and fight in battlegrounds.

Planned features include lightweight headless instances, WASM viewers from bot perspectives, verifier and logging hooks, and controls allowing an agent to manage a team of playerbots as a human would, for evaluation and data generation. Existing LLM-dialog mods do not establish full autonomous characters. The post provides no repository, client build or compatibility tests and does not say AI performed the client reversing; REA is not stated. AI is primarily the intended client user here. This collection did not run the game or verify cleanroom separation or asset provenance. The author's willingness to redo assets if required is not completed asset replacement.
