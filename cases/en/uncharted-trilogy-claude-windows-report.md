# Uncharted 1–3: a reported Claude-assisted native Windows port

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-16
Stage: Needs verification

A quote post says Uncharted 1, 2 and 3 are playable on Windows PC, describing Claude-assisted reverse engineering that translates PS4 code to Vulkan for native Windows builds with a shared launcher. It also lists 60/120 FPS, DLSS, FSR, frame generation, keyboard/mouse and controller support, and subjectively praises performance. This is a circulating report about three specific games, not source code or reproducible validation. No repository, build or hardware test was obtained, so implementation of these features is not confirmed and frame rates are not presented as general performance. REA use is unconfirmed. No game files are distributed and release authorization is not inferred.
