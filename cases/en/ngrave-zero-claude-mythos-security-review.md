# NGRAVE ZERO: announcing a Claude Mythos review of wallet firmware and apps

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-24
Stage: In progress

At 21:20:35 Beijing time on October 23, 2026, NGRAVE's official post announces acceptance into Anthropic's Cyber Verification Program and use of Claude Mythos to look for vulnerabilities in ZERO hardware-wallet firmware, companion apps and infrastructure, aiming to fix them before exploitation. This is a concrete AI security-review plan for an existing wallet system.

The post provides no firmware version, analysis input, decompilation toolchain, discovered vulnerability, patch or reproduction record, and does not mention REA. It is recorded as in progress, not evidence that firmware is secure, that a model cracked the wallet, or that a valid vulnerability has been found. Checking the public post is not independent verification of program eligibility or an audit of the product.
