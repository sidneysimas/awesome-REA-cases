# DJI Mic Mini 2: an APK-based macOS settings client using REA and Claude

Category: Hardware and interoperability · REA
Record date: 2026-10-20
Stage: Needs verification

At 23:26 Beijing time on October 20, 2026, aarohan (_nahoraa) says a DJI Mic Mini 2 bought for recording demos lacked a macOS app, leaving many settings unavailable. After cloning REA, the author reportedly asked Claude to make a Mac application using the APK and says it worked well. The concrete purpose is cross-platform access to existing hardware settings, not microphone firmware reconstruction.

Reading the original post confirmed the author and an attached image, but not which settings, APK version, USB or Bluetooth transport, Mac source, signing or device-test logs. This collection did not test hardware. It does not establish an official client, complete parity or compatibility with all models. REA and Claude remain author-attributed, and Mic Mini 2 is preserved exactly as the source names it rather than silently corrected.
