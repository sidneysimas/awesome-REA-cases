# Screen recorder/editor: withdrawing a REA version and rebuilding with Claude and Electron

Category: Applications and clients · REA
Record date: 2026-10-20
Stage: In progress

At 18:08 Beijing time on October 20, Yıldız Dikme (YildizDikme) reports making the GitHub repository and YouTube video for an earlier REA-developed application private. After researching licenses, the author says a screen-recording and editing application was rebuilt from scratch with Claude and Electron, without REA this time. The plan is to share it free after testing and use it for the author's own edits; comparable products are described as costing about $100.

This records a concrete change in project direction and release plans, not proven license infringement or an announcement that the new application is already public or functionally equivalent. The old reference product and repository are not named. It is not merged with another author's Screen Studio reconstruction. Reading the original post confirmed the author's identity but supplied no public code. This collection has not tested the new version, and the extent of the earlier REA analysis remains unknown; the transition is in progress.
