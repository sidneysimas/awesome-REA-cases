# LG OLED: Damos uses Claude Code for a native QML home and system changes

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-24
Stage: Needs verification

At 00:48:46 Beijing time on October 24, 2026, Damos (@Damos1212) adds details of an LG OLED modification: blocking LG ad and telemetry domains, disabling background-app preloading, remapping HOME and blocking firmware updates to retain root. He says each change has a one-line undo. He reports reclaiming about 80 MB and opening the home in about 350 ms versus about one second for a web launcher, without a measurement method.

The same author's parent post at 00:48:13 supplies the goal: replacing the default ad- and tracking-heavy home with a Sega Emerald Coast, Mario Sunshine and Frutiger Aero-inspired interface. He describes giving Claude Code visual directions, having it build and retrieve screenshots from the TV, then providing human feedback. The home uses native QML on LG's own UI engine, with GPU shaders for water, city, palm and liquid icons, plus generated audio. It is not a new operating system: it is webOS, a rooted environment through Homebrew Channel, and a new home app.

This is a concrete report of AI-assisted interface and system-behavior modification, not evidence Claude performed the root or reverse-engineered all of webOS. REA is not mentioned. No model, firmware, code, undo commands or controlled performance tests are supplied; blocking known domains does not establish removal of every ad or tracking path. The same-day parent is supplementary evidence, not another candidate. No TV was connected or code executed, and update-blocking or safety effects were not tested. The case remains unverified.
