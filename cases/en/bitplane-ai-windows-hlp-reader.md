# Windows HLP: bitplane reports an AI-assisted parser, converter, library and TUI

Category: Applications and clients · Other AI-assisted work
Record date: 2026-10-24
Stage: Needs verification

At 17:05:27 Beijing time on October 24, 2026, davidsong (@bitplane) lists a Windows HLP parser, converter, library and terminal interface among AI-assisted projects. The purpose is restoring access to old help files. He describes difficult work without a measured duration or a named model or REA use.

The supplementary winhlp README, last changed September 26, 2026 before this window, explicitly describes a pure-Python implementation derived from helpdeco source by Manfred Winterhoff, Ben Collver and Paul Wise, published under GPLv2. It is not a from-scratch black-box recovery. The document lists WinHelp 3.0, 3.1, Windows 95 and MediaView .mvb support, JSON or browsable HTML export and searchable terminal navigation. Validation across about 6,500 real help files and text comparisons against helpdeco are project reports.

This collection ran neither the program nor comparison scripts and checked neither corpus nor output completeness. The case remains unverified: a support list does not establish lossless conversion of all historical documents, and previous helpdeco work is not an achievement of this AI project.
