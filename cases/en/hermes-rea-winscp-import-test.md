# Hermes/REA: a WinSCP import test and a version correction

Category: Applications and clients · REA
Record date: 2026-10-16
Stage: Analysis test

Two introductions to a Hermes REA plugin in this window say it pins rea-agents 6.4.0, offers about 170 MCP tools through on-demand tool search, and includes skill rules requiring confirmation before executing targets or connecting Android devices. The specific analysis target is WinSCP GUI, with a reported 663-second Ghidra import. No sample version, machine configuration, subsequent function analysis or reconstruction tests are given, so WinSCP reconstruction is not established. The 22:25 post says the stable release is installable; a later 23:42 explanation instead says v0.22.2 fails with unknown keys ['timeout'] and needs a per-server timeout fix. This record preserves the contradiction and correction, treating no version advice as a current official installation guarantee. Tool count and schema size are also post-reported; this collection did not test the plugin.

Both sources dated October 15; 663 seconds is a recounted project test, not timing by this collection. No installation performed.
