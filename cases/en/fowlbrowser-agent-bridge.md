# fowlbrowser: an existing-session browser bridge for agents

Category: Applications and clients · REA use unconfirmed
Record date: 2026-10-12
Stage: Needs verification

In this review, champi asks whether argofowl's new browser extension came from the previously planned reverse engineering of the Codex extension. The author's corresponding release post and README introduce fowlbrowser: MCP, a local messaging bridge and an extension let Claude or other agents use existing browser tabs and login sessions, work in the background, and hand login and payment back to the user, with a public repository. It currently supports only macOS; Chrome and Helium have been tested, while other Chromium browsers have received less testing. A concrete interoperability project has been released, but its reverse-engineering attribution remains a question, not author confirmation of recovered Codex protocols. Performance comparisons are only the author's small-sample reports; this collection did not run the extension.
