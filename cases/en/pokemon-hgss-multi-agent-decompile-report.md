# Pokémon HeartGold/SoulSilver: a secondhand multi-agent decompilation and cost report

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-16
Stage: Needs verification

An earlier reply says multiple AI agents decompiled chunks of Pokémon HeartGold and SoulSilver, assembling them in one month with roughly 71 billion tokens using Claude/OpenAI APIs. It explicitly says the work was subsidized and about $56,000 is a hypothetical API list-price estimate, not an actual bill. At 15:01 Beijing time on October 16, @Pirat_Nation's new circulating post says all 4.1 MB of HeartGold's compiled code became readable C/C++, that the repository also covers SoulSilver, and that it can generate byte-identical ROMs. Completion and matching have not been checked against the repository or build output. At 15:25, @Alex_Vainshtein replies that the project builds on pret's existing decompilation and tooling, urging separate measurement of the upstream baseline and new agent work. This attribution warning is not an audit of either contribution, but prevents presenting the total result as AI work from zero. A checkable repository address, matching report, developer confirmation and cost worksheet were not obtained. Clean-room work, independent reproduction and a completed playable port are not established. The newer post's simplified '$56,000 cost' wording does not override the earlier subsidy and hypothetical-cost caveat. REA use is unconfirmed.

Earlier October 16 candidate snapshot: 1 like, 22 views; roughly 71 billion tokens, one month and $56,000 are not independently verified.
October 16 candidate snapshot for the 15:01 circulating post: 462 likes, 14,048 views, 29 reposts; engagement does not prove matching or contribution shares.
