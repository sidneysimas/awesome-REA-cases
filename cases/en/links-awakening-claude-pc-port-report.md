# Link's Awakening: the Claude-assisted LASRecomp project

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-15
Stage: Needs verification

The earlier overview says Link's Awakening was recompiled to PC almost entirely with Claude Code. An October 15, 14:17 candidate adds the project name LASRecomp and the caveat that particular actions cause crashes. Reading peiikai/LASRecomp's public README then confirmed the target as the 2019 Switch version v1.0.0. The project describes static recompilation to native Windows, macOS and Linux applications. The author explicitly says almost all code, tooling, reverse engineering and documentation were done by Claude Code, with humans directing, testing and reviewing. It is currently beta: macOS supports only Apple Silicon, Linux ARM is experimental and untested on actual hardware, and known crashes include inspecting a particular dresser and returning to the title screen. The project contains no game files, assets or fonts; users must lawfully provide the original game. This collection did not compile or run it, quantify AI's contribution or guarantee full behavioral equivalence. The existing ID and early source are preserved; public documentation is retrospective supporting evidence added this review.

Current secondhand snapshot: 144 likes | 24,723 views | 16 reposts; public README confirms the project and AI claims, without independent execution.
A new October 15, 18:04 account claims a 60 FPS lock, internal rendering up to 4× and problems above 60 fps. Rereading the public README this review confirmed only adjustable internal rendering and beta/crash limitations, not 60 FPS or a 4× maximum. Exact figures remain secondhand rather than current cross-platform measurements.
