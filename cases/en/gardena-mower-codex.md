# Gardena mower: Codex firmware and motor research, with Claude continuing development

Category: Hardware and interoperability · REA use unconfirmed
Record date: 2026-10-19
Stage: In progress

On October 13, @BderKhan reports obtaining motor control of a Gardena mower with Codex, using phone-to-ESP32 Wi-Fi followed by Bluetooth to the mower, with new firmware in development. At 03:49 Beijing time on October 19, the same author says Codex decompiled robot-mower firmware. Claude reportedly said it could not continue; the user used Codex for unlocking and turning the work into a project, Claude for development and Codex again for deployment.

Retrieving both posts confirms the same author, so this extends the existing Gardena case rather than guessing a different mower. The follow-up does not repeat the brand; attribution rests on the author and reference to his own research. No model, firmware version, code, original refusal logs, complete-replacement validation or safety tests are supplied. The model division is personal experience, not proof that all Claude instances refuse or Codex can unlock every device. Motor control does not establish reliable safe operation. REA use is unconfirmed; no device was independently connected, deployed to or retested.

Evidence boundary: author report; not independently retested
Firmware work remains in progress; REA use unconfirmed
October 19 follow-up candidate snapshot: 1 like, 10 views; no deployment log.
