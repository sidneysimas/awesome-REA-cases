# Six single-feature rebuild ideas: from slash menus to smart snapping

Category: Applications and clients · REA
Record date: 2026-10-16
Stage: Needs verification

An October 16 proposal recommends investigating one feature in software the user is authorized to inspect, rather than cloning an entire app. Its six targets are Notion's slash-menu search and insertion; Linear's command-palette fuzzy search and keyboard navigation; TradingView trendline anchor dragging, price snapping and undo; Discord typing-status events and inactivity timers; Figma alignment guides and snapping; and Spotify seeking with synchronized audio position and UI updates. The author suggests REA with Claude Code/Opus 5.5 to trace interaction, functions, calls, events and state, separate findings from assumptions, write SPEC.md with inputs, outputs and edge cases, then build an original implementation, compare identical inputs and log mismatches. The post does not report completing the six features or supply code or test results. This is a concrete research route and set of feature ideas, not a reconstruction of platform protocols or backends.
