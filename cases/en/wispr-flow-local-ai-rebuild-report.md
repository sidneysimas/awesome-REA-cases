# Wispr Flow: a reported local dictation rebuild with DeepSeek and Opus

Category: Applications and clients · Other AI-assisted work
Record date: 2026-10-20
Stage: Needs verification

At 16:52 Beijing time on October 20, Vraj (vraj_ai) says he reverse-engineered Wispr Flow and built a local alternative with DeepSeek V4.1 Flash and Opus 5.5, aiming to replace a subscription he describes as $15 per month. The reported core interaction is holding a hotkey, speaking and typing the result into any application. Listed cleanup features remove filler words, add punctuation, turn rambling into lists and handle spoken corrections. Command Mode reportedly rewrites selected text from spoken instructions.

The author also claims per-app styles for Slack versus email, a personal dictionary learning from corrections, Whisper fallback for other languages, fully offline operation, macOS/Windows/Linux support and an MIT license. Reading the original post confirmed only these statements and an attached video, not an expanded code address, model-deployment instructions, platform tests or feature comparisons with the original. This collection did not watch the complete video or run an application. It does not verify the all-features-free claim, offline privacy or license, and REA use is not established. This target is distinct from the existing Typeless alternative.
