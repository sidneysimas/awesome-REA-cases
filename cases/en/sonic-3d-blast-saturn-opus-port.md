# Saturn Sonic 3D Blast: byte-matching decompilation and a native PC port

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-16
Stage: In progress

On October 16, @TheOneMrMatt acknowledged Opus accelerated byte-matching decompilation and said an AI disclosure was removed because of anti-AI reactions. Historical updates identify Saturn Sonic 3D Blast: in July the author studied SH2 code and frame-by-frame state from a custom emulator; on August 3 they reported using Claude Code to recreate a Hitachi compiler environment, recovering the SSSS.BIN Special Stage engine as C and handwritten assembly with byte matching, while three other executables were blocked by a particular GCC environment. On September 26 they reported 100% decompilation progress, with regional versions, documentation and porting still to do. An October 16 update at 06:04 Beijing time, before this window, describes a native C/SDL PC port with software rendering and OpenGL presentation, widescreen and Special Stage interpolation. Edge garbage and polygon seams remain; first release is planned for November 20 with user-supplied US/EU/JP disc files. Historical posts identify the target, AI use and stage, not new-window developments. Matching and visual results are author reports. This collection did not obtain and run source or treat the future release as already shipped.

Current-window statement candidate snapshot: 0 likes, 14 views; supplementary originals range from July to October 16 and are not new-window achievements.
