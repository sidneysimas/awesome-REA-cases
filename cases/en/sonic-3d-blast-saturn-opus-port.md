# Saturn Sonic 3D Blast: byte-matching decompilation and a native PC port

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-16
Stage: In progress

On October 16, @TheOneMrMatt confirmed Opus accelerated byte-matching decompilation and said an AI disclosure had been removed because of anti-AI reactions. Historical updates identify Saturn Sonic 3D Blast: July research used SH2 code and frame-by-frame state from a custom emulator; on August 3 the author reported recreating a Hitachi compiler environment with Claude Code, recovering the SSSS.BIN Special Stage engine as C and handwritten assembly with byte matching, while three other executables were blocked by a particular GCC environment. On September 26 they reported 100% decompilation, with regional versions, documentation and porting still required. The October 16, 06:04 update describes a native C/SDL PC port with software rendering and OpenGL presentation, widescreen and Special Stage interpolation, but edge garbage and polygon seams remain. First release is planned for November 20 with user-supplied US/EU/JP disc files. These historical materials provide stage and technical background only. In the new 12:26 candidate, the author explicitly says this is not static recompilation: it is a native PC port built from what they describe as fully byte-exact, documented decompiled code. Agentic AI reportedly reduced a process that might have taken years by hand to a few months. This is retrospective author attribution, not a controlled labor comparison or new public matching output independently checked here. This collection did not obtain and run source, and retains the visual defects and future-release caveat rather than presenting the statement as a shipped or independently validated result.
