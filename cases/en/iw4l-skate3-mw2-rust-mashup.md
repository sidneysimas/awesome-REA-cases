# 2010 Rust Rewrite Mashup: Skate 3 in MW2 maps

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-16
Stage: Needs verification

A secondhand introduction in this window describes 2010 Rust Rewrite Mashup, reportedly based on IW4L's from-scratch Rust rewrite of MW2, bringing Skate 3 skateboarding into 2009 Modern Warfare 2 maps and Minecraft worlds. The post says Windows users need their own MW2 and Xbox 360 Skate 3 files and that the repository contains AI-agent instruction files and an LLM-use disclosure. It also emphasizes the community's long study of Skate 3 and the creator's roughly six months building Xbox 360 recompilation tools; AI accelerated coding on those foundations. This is not overnight automatic decompilation of two complete games. The repository and runtime records were not obtained, so this is secondhand and not assumed to be the same project as Maurice's MW2 decompilation or Universal Modder.

October 15 source; roughly six months is secondhand effort, not independently checked; REA unconfirmed.
