# GameCube/Wii PowerPC support request

Category: Games and preservation · REA use unconfirmed
Record date: 2026-10-12
Stage: In progress

GameCube and Wii are Nintendo consoles whose game programs use PowerPC processors and the DOL format. The issue author says they already analyzed an unnamed Wii game outside REA using headless Ghidra and wants function, caller and data inspection integrated into REA. The discussion proposes supporting general PowerPC ELF first, then DOL. The evidence is actual external research and a specific integration request, not a Wii game reconstruction completed with REA.
