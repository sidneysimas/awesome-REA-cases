# Harness Studio: a reported top-down open-source Claude Code Desktop reimplementation

Category: Applications and clients · Other AI-assisted work
Record date: 2026-10-23
Stage: In progress

At 10:25 Beijing time on October 21, 2026, Vignesh (@vigneshv1cky) says he reverse-engineered Claude Code Desktop and brought every feature to his project through a top-down approach rather than REA. Earlier thread retrieval identifies Harness Studio, an open-source macOS/Linux coding desktop allowing users to choose model providers and use their own keys. His 05:59 promotion that day was merged as a deferred earlier source; the 03:36 introduction supplied context, not a newly published current-window project.

A new candidate at 02:26:43 on October 23 is by the same author. It adds that DeepSeek harness is the base and features were added one at a time, aiming to keep a desktop workflow he likes without being locked to one provider or subscription. It advertises bring-your-own API keys for Claude, OpenAI, Gemini and local models. The base project is distinguished from the desktop being investigated; DeepSeek's base is not original Claude source.

No verifiable repository revision, implementation comparison or test output was obtained. Every feature is not verified equivalence, universal provider compatibility or independently established cleanroom provenance. Model access is a stated purpose, but which model performed any reversing remains unspecified. The author explicitly denied REA use earlier and the new post does not reverse that statement. The entry stays other-ai and in progress. This collection did not run the desktop software or access API keys.

Latest candidate originally posted 2026-10-23T02:26:43+08:00. October 21 sources are retained; newly advertised support remains an author claim.
