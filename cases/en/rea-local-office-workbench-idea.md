# A local REA workbench: combine investigation and personal office workflows

Category: Applications and clients · REA
Record date: 2026-10-16
Stage: In progress

On October 16, @ModengSir discussed an REA workbench deployed the previous day, saying Codex could build it, and proposed expanding it into a personal operations platform: a content-topic radar, agent-connected skill workflows such as public-account formatting, idea capture, plan completion tracking, an REA interface, and image/video generation interfaces. A same-day reply says the author's local workbench already contains an REA interface. The concrete use is combining an investigation entry point with daily workflows in one local interface. The other functions are suggestions in a request for requirements, not all delivered features. No investigated application, backend isolation design, code or acceptance results are supplied; an interface is not a new reverse-engineering engine.
