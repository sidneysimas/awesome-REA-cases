# A cat household's robot vacuum: an REA idea for vomit detection

Category: Hardware and interoperability · REA
Record date: 2026-10-18
Stage: Needs verification

At 20:44 Beijing time on October 18, a user with two cats compares cleaning, obstacle crossing and low-clearance behavior on a Roborock P20Max and Ecovacs T90Pro, leaning toward Sam's Roborock P30 Member. Concerned that a robot could spread cat vomit, the author proposes using REA to investigate the robot and add recognition that distinguishes vomit from ordinary stains.

This is a firmware or control-extension idea rooted in a concrete household need, not an implemented vision model or validated avoidance system.
