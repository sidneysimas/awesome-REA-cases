# Star Fox and Sonic CD: reported AI-assisted native ports

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-13
Stage: Needs verification

Aman says Opus 5.5 ported Star Fox, Star Fox 2 and Sonic CD to Windows, macOS and Linux. The three short links do point to arwing, arwing2 and littleplanet respectively. Their READMEs describe disassembly and static recompilation to C with interpreter fallbacks retained, rather than recovery of readable original source. Public documentation includes author-reported matching and runtime comparisons, but this review did not run them or confirm that the named model and a single prompt accomplished everything. The three related projects are grouped as one circulating case from the same post. Users need their own game images; assets are not provided.

Evidence: circulating post and three actually associated repositories
Boundary: static recompilation is not complete high-level source recovery; not run
