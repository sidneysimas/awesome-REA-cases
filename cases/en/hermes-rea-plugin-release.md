# Hermes REA plugin: a reported MCP and adapted Skill release

Category: Applications and clients · REA
Record date: 2026-10-16
Stage: Related project

A circulating post says an official REA plugin for Hermes has been released, installing REA MCP and a Hermes-adapted reverse-engineer-anything Skill together. It lists native binaries, .NET, Electron, Android packages, firmware, browser captures and live process activity as inspection targets. Roughly 170 tools are reportedly discoverable behind tool search to keep context light. The stated entry point is hermes plugins install rea, requiring Hermes 0.22.1 and Node, with users supplying Ghidra, Hopper or IDA for native decompilation. The post also says the Skill tells the agent to ask before running programs or changing a device. The poster ends with plans to install that night, so this is not a completed installation test or target-analysis acceptance report. Official attribution, version, counts and permission guidance remain the post's claims; no installation or execution occurred in this review. This integration project is distinct from the existing Hermes/WinSCP import test and does not imply support in every Hermes version or enforced blocking of every operation.

October 16 candidate snapshot: 6 likes, 549 views; plugin scope and roughly 170 tools are post claims, not tests by this collection.
