# A 2 GB Android TV box as an always-on agent host: a Claude setup account

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-20
Stage: Related project

At 02:51 Beijing time on October 20, an author claims Opus 5.5 repurposed a provider-supplied 2 GB TV box as a 24/7 agent-tool host: identify platform and 32/64-bit architecture from a photo, install a suitable Linux shell, add a wake lock and battery whitelist, connect a Telegram bot responding only to its owner, and optionally use the TV as a terminal. Model inference explicitly remains in the cloud.

Claimed scope is Android TV, Google TV and Android 7+ Fire TV. A step-by-step video is claimed but not fully watched here. No box model, shell implementation, repository, background-survival or security tests are supplied. Rooting, firmware modification, zero open ports, API-key secrecy and unattended overnight operation are unconfirmed. The $899 Mac Mini and eight-times-RAM comparison is the author's, not performance equivalence; free reused hardware does not remove cloud-model bills. REA is not explicit.
