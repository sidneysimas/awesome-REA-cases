# PS5 security: reported AI-assisted investigation

Category: Hardware and interoperability · REA use unconfirmed
Record date: 2026-10-28
Stage: Needs verification

PS5 is Sony's game console. 0x0SojalSec says AI reverse-engineered its security mechanisms within weeks and includes a jailbreak-store image. Original researcher records, AI tools, firmware revision and code are absent, so AI's contribution cannot be confirmed and access to the entire game library is not established. An October 15, 2026 third-party report names 2tonejordy, says an LLM helped rediscover a known vulnerability and mentions Sony's bounty. This adds a named lead, but does not establish whether the bounty vulnerability and LLM experiment were the same work or justify attributing all mentioned PS5 emulator, Linux or Windows projects to AI.

At 04:07:10 Beijing time on October 28, 2026, AI Observer (@ppmmzzcn) posts an AIBase summary citing IGN: Jordy allegedly used generative AI to find a high-risk vulnerability and received $50,000 through Sony's reporting channel, converted by the post to about RMB 334,000. The same post says another security engineer had already found the vulnerability and was researching Linux on firmware 13.60 through 14.0. This is appended to the existing Jordy lead, not a separate PS5 case, and the predecessor's Linux work is not credited to Jordy or AI.

Lookup confirms only this summary's original attribution and text. IGN's full article, vulnerability identifier, original analysis, Sony confirmation, bounty record and reproduction logs were not obtained. Amount, severity, firmware range and payment are secondhand claims, not proof of an original AI discovery, successful Linux installation or defeat of the whole console security architecture. REA is unknown and status remains unverified. No console was operated here; no game assets, cracking steps or pirate-store entry points are provided.
