# Dell keyboard and mouse: receiver-protocol research for an Omarchy battery widget

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-20
Stage: Needs verification

At 17:34 Beijing time on October 20, Mike Harrison (mikejharrison) reports that Dell's peripheral software does not support Linux, leaving him unable to see his keyboard and mouse battery levels in Omarchy. He says he and ChatGPT reverse-engineered the receiver protocol, then his Claude Code agent built the widget. The goal is desktop interoperability where the vendor's companion software is absent.

Reading the original post confirmed the author and this division of work. It includes an image but no keyboard, mouse or receiver model, protocol fields, source code or replayable tests. This collection did not query a device or measure battery accuracy. The widget report does not establish support for all Dell peripherals, and REA use is not stated.
