# Codex browser annotations: finding the interaction bridge

Category: Applications and clients · REA
Record date: 2026-10-12

宝玉 wanted to understand how webpage annotations in the Codex / ChatGPT app's built-in browser reach the conversation input, so the same interaction could be integrated into the author's own webpage. The author had Codex with REA inspect Electron code, personally sent messages to assist, and built a test page. The author reports that document.oai.annotation.request() can open a comment box and populate its content, but cannot directly append the comment to the input. The result identifies and partly validates an interaction interface, rather than fully implementing automatic messaging.
