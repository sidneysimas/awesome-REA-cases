# Final Fantasy XIV: a claim of Claude-assisted bosses, graphics and UI on a decompilation

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-19
Stage: Needs verification

At 17:15 Beijing time on October 19, @_voidstranger (Yuyu) claims to have used a recent Final Fantasy XIV decompilation with Claude to improve gameplay, listing new bosses, graphics, UI, more chores and customization. The stated target is modifying an experience on existing game logic, not asking Claude to build a same-named game from scratch.

No decompilation project identity, game version, repository, patch, demonstration or test record is provided. Retrieving the original confirmed attribution but does not distinguish actual development from a joke or reused viral copy. This remains an unverified author claim, not confirmation of a recovered complete FFXIV client or server, official-service connectivity, playable bosses or better performance. REA is not specified and the game was not run. Similar wording in posts about other games proves neither shared code nor authenticity.
