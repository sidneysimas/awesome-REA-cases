# Grokbot: a SOL 6.1-assisted Harness/Host remote-computer execution rebuild

Category: Applications and clients · Other AI-assisted work
Record date: 2026-10-19
Stage: In progress

At 04:58 Beijing time on October 19, @Stephen4171127, whose display name is 熊布朗, reports three days reverse-engineering and running Grokbot's Agent Harness and Host core execution chain, version 0.72.0-pre.11. The new shell was not investigated and an older UI was retained. Although the initial intention was to test REA, the author explicitly credits model-driven code reading, analysis scripts and comparative verification, mainly with SOL 6.1. The result is not attributed entirely to REA.

The remote environment reportedly uses Cursor universal's sand-box-latest image deployed with Docker on the author's VPS. The claimed tested chain is: main agent calls a model, delegates to a computer subagent, views a remote desktop screenshot, clicks to open Chrome, then receives the subagent's completion report. The purpose is restoring a runnable and modifiable execution core rather than merely imitating the UI. Turning the recovered core into maintainable source and completing remaining host capabilities are next steps.

Retrieving the original confirmed the author and full wording. No recovered source, reproducible logs or independent verification is public, and the author describes personal use rather than a GitHub release. Three days and the successful chain remain author reports, not evidence of full Grokbot equivalence or complete recovery.
