# Mario's jump in Halo: an unverified six-parameter REA claim

Category: Games and preservation · REA
Record date: 2026-10-16
Stage: Needs verification

A circulating post claims REA and Opus 5.5 located jump logic in an N64 Mario ROM, studied a Halo player-movement integration point, and carried six floating-point parameters into a new controller, claiming no Nintendo code was copied. It outlines studying the original, studying the receiving game and writing a controller, but provides no specific game versions, offsets, specification, code or test output.
