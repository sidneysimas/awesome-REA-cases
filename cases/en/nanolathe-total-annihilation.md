# Nanolathe: reimplementing Total Annihilation

Category: Games and preservation · Other AI-assisted work
Record date: 2026-10-13
Stage: Needs verification

Alexander Tanasie shared Nanolathe, saying Claude, Codex and DeepSeek supported reverse engineering of the Total Annihilation engine. The short link does lead to the official site, and the corresponding public Go repository describes a clean-room engine with incomplete compatibility and research rules for human and agent contributors. The project's existence and reconstruction target are checkable, but specific model contribution shares still come mainly from the circulating post. It was not run in this review. The full game requires the user's own data; an open-source engine does not make game content free.

Evidence: circulating post and public repository
Stage: ongoing development with compatibility gaps; not independently run
