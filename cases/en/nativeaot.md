# .NET NativeAOT recovery request

Category: Applications and clients · REA
Record date: 2026-10-12
Stage: In progress

NativeAOT compiles .NET programs ahead of time into native machine code, preventing direct reading of C# as with ordinary .NET assemblies. A user wanted REA to recover relevant information. Some metadata support has been added, but the available material does not establish recovery of the original C# project, and the Windows workflow also has limitations. This is a capability request and progress record.
