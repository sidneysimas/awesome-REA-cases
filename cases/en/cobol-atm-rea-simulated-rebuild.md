# COBOL ATM ledger: an explicitly simulated REA/multi-agent rebuild proposal

Category: Applications and clients · REA
Record date: 2026-10-20
Stage: Needs verification

At 17:44 Beijing time on October 20, an author uses a circulating legacy-rewrite demonstration to describe simulating the same recipe on a COBOL ATM ledger. REA would turn 146 old files into one specification, Opus 5.5 would plan once, 12 Sonnet 5.5 agents would each rebuild one module, and old/new behaviors would be replayed. The purpose is to explore whether cheaper-model delegation could reduce ledger-migration costs.

The post gives 120/120 matching behaviors and costs of $4.85 for Opus alone versus $0.97 for a swarm, while explicitly stating all simulated. These are figures in the author's simulation narrative, not an executed ledger, real invoice or independent experiment. The opening $240,000 job becoming seven minutes and $0.88, and the REA star count, are cited background rather than project results. No original files, specification, code or replay logs are supplied. This collection does not verify the figures or present this as a successful financial-system migration.
