# Unity/Valheim assemblies

Category: Games and preservation · REA
Record date: 2026-10-12
Stage: In progress

Unity games often compile C# logic into Assembly-CSharp.dll; Valheim is a survival game built with Unity. A user tried analyzing the game's assembly with REA. Related discussions include tool fixes and independent tests on real .NET SDK assemblies, but do not establish a successful retest of the original Valheim target, much less a completed game modification.
