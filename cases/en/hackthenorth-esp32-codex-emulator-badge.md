# HackTheNorth badge: Codex-assisted firmware turns an ESP32 into an NES and Gameboy handheld

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-26
Stage: Needs verification

At 04:55 Beijing time on October 26, 2026, Mika Vohl (@AmateurMika) described modifying a HackTheNorth event badge: an ESP32 running at 160 MHz with only 4 MB of flash. The aim is to run NES and Gameboy games directly on the badge rather than leave it limited to its original event-device role.

The author explicitly reports using Codex to develop custom C/C++ firmware and port NES and Gameboy emulators. Because local storage is small, new games are fetched from the author's own server over Wi-Fi. This is a report of AI-assisted firmware development and ports of existing emulators, not proof that Codex decompiled both consoles from scratch. No source establishes investigation of closed badge firmware. REA use is unconfirmed.

Supplementary lookup confirmed authorship and wording. The post includes a video, but this collection did not play it to verify operation and obtained no source code, upstream emulator names, badge revision, frame rates, compatible-game list or execution logs. Running ROMs directly does not establish that all games are playable, performance is adequate or compatibility has passed acceptance testing. It is included as an unverified hardware interoperability/porting report; no code was executed, dependencies installed or game assets downloaded.

Author report: a 160 MHz ESP32 with 4 MB flash, fetching additional games over Wi-Fi from a personal server; operation and performance were not independently verified.
