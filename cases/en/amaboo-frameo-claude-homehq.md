# AMABOO Frameo: Claude Code adapts an existing Home HQ frame setup

Category: Hardware and interoperability · Other AI-assisted work
Record date: 2026-10-17
Stage: Needs verification

At 08:20 Beijing time on October 17, @InvestingVault recounts Netherlands user @j3lte following @wesbos's frame hack, pointing Claude at Wes's GitHub repository, adapting an AMABOO 10.1-inch Frameo into a Home HQ kiosk and submitting a setup-documentation PR. The text describes enabling ADB through Beta Program, backing up firmware first, disabling two auto-updaters, making Home HQ the home screen, then disabling Frameo. The zipped backup reportedly measured about 800 MB. This unit's built-in browser was recent enough not to need replacement. The account warns to wait about 10 seconds after disabling Frameo before rebooting or the app returns, and says another builder with the same board experienced it.

This is an account of AI-assisted old-hardware adaptation and configuration, not recovery of Frameo source or confirmation of newly reversed protocols. The source explicitly says there was no firmware flashing and changes are reversible. This collection did not inspect the PR, test restoration or run the device; other boards are not guaranteed compatible, and about 800 MB and 10 seconds are not universal specifications.

Claude Code follows an existing project; REA use unconfirmed; reversibility and same-board behavior not retested.
