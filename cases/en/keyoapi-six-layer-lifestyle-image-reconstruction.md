# KeyoAPI's six-layer visual reconstruction: a hand-analyzed cafe image becomes a different bookstore portrait

Category: Algorithms and feature recovery · Other AI-assisted work
Record date: 2026-10-28
Stage: Analysis test

At 10:39:28 Beijing time on October 28, 2026, KeyoAPI (@KeyoAPI) recalls a roughly 42-second mobile image-to-prompt tutorial and says it remade the closed loop, not the tutorial UI: manually study the visual structure of a demonstration still, write a six-layer reverse sheet and generate an original lifestyle portrait using gpt-image-2 through Keyo. Same-day thread replies from 10:43 to 11:14 identify subject, scene, style, color, composition and details as the layers. The reference depicts an outdoor cafe, yellow jacket and latte. The remake deliberately changes identity and likeness to a South Asian woman, burgundy sweater, rainy bookstore window and chai mug.

The author reports finding gpt-image-2 among 119 listed models and making one attempt each for two 1536×1024 images, taking about 33.4 and 33.0 seconds; the second is the root image. The original extractor site was not called for generation, and the six-layer card was drawn with PIL rather than a model. These are author-run figures, not independently measured API results or speed guarantees. The author admits the source clip never shows the final extracted prompt, so the handwritten specification is not a tool export. The result still resembles a cozy cafe and misses micro-props, not a perfect clone or recovered original prompt. The use is learning composition and re-creating it in a different scene. AI performs regeneration, not established automatic inference. Evidence and promotion come from the same service account. Image attachments exist but were not independently visually compared. REA is unspecified. No API was called or image generated here.
