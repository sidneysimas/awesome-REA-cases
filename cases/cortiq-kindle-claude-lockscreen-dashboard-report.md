# Kindle锁屏仪表盘：Cortiq称Claude辅助识别固件、越狱与去广告

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-25
阶段：待验证

2026年10月25日21:56:40（北京时间），Cortiq（@0xCortiq）称把Kindle接入MacBook，让Claude Code移除广告并把锁屏改成有用的信息屏。作者报告模型识别设备型号和固件，指导适用版本的越狱，移除special offers画面并设置自动刷新仪表盘；显示时间日期、未来五小时天气、当天日历、待办与X粉丝数。用途是复用电子书锁屏，不是重建整个Kindle系统。

补查原帖确认作者和两张附图，但没有设备型号、固件版本、具体越狱工具、代码、刷新间隔或测试记录。不能把指导既有越狱写成AI发现新漏洞，也未确认REA使用。作者称电池可用数周，未提供测量，且不能从电子墨水屏保持画面的特性直接推导联网刷新系统的整体续航。帖首9300余书签指此前iPhone提示词，不是本Kindle项目的热度，不计为本案例传播快照。

这是Cortiq的作者自述，不与furkan的Raspberry仪表盘或Kuberwastaken的AI用量屏合并。未运行提示词、连接Kindle、访问日历/X账号或核验去广告、越狱和刷新效果；状态保持待验证。

型号、固件、代码、刷新频率和越狱路线未名；作者报告，未独立运行。
数周续航无测量；9300余书签属于先前iPhone提示词，不是Kindle热度。
