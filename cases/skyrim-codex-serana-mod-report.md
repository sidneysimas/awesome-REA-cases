# Skyrim：Codex 调整瑟拉娜召唤外观并排查 Mod 故障

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-18
阶段：待验证

10月18日13:16（北京时间），作者说重新安装《上古卷轴5》后，让 Codex 修改已有 Mod：某召唤法术使用原版瑟拉娜外观，他希望改为已装美化后的样子，并美化其吸血鬼大君形态。作者还报告解决黑脸，以及某随从因身形或动画异常持续发出滋滋声的问题，称 Codex 会发现并调用自己已装的工具。

这是对既有游戏内容的AI辅助修改自述，没有Mod名称、工具日志、补丁或前后测试，不能确认具体是否涉及二进制逆向，也不能验证全部故障确已修好。作者最后提出若有精力，或可让 Codex 逆向优化整款老游戏为高性能现代版本；该部分只是 idea，不是已完成引擎重写或性能提升。REA参与未确认，未独立复现。

10月18日候选快照2赞、1022浏览；Mod修复为自述，未提供补丁，性能优化未实施。
