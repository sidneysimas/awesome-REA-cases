# GameCube反编译：Douglas报告Opus与GPT协作补编译器，过度验证拖慢后续项目

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-26
阶段：进行中

2026年10月24日23:35北京时间，Douglas（@douglastweets）在模型使用讨论中介绍自己的GameCube游戏反编译项目。作者称早期沿用GPT-5.4时期的harness，之后撤掉多余约束，让Opus 5.5、GPT-6 Astra及后来的Sol自行选择方法；首个项目后期Opus每天处理约100个困难函数，Opus与Astra还合作重建了一个缺失的编译器版本。作者说Opus继续做该游戏的移植与soak testing，自己也手动测试。游戏名称、仓库与编译器型号未公开，不确认字节匹配或移植完成。

10月26日01:32的另一候选补充失败路径：GPT在后续项目复制首个流程时加了奇怪的safeguards，让7000多个函数中的每个验证花数小时。作者澄清不是网络安全拒绝，而是模型曲解流程指引；也承认自己未及时监督，且一些会话已因磁盘占用清理。不能将缺少原会话的个人比较升级为可复现性能基准。

原帖另谈DDR/PIU歌曲裁剪和新谱训练，这是普通生成开发，不作为第二个逆向目标。该GameCube系列因有明确平台、编译器重建、进展与测试边界，作为进行中作者报告收录；未将它并入基线Wii PowerPC支持请求，未运行目标游戏或模型。

两条均为往期补审；时间与速度是作者自述，未提供函数级验收或独立计时。
