# Apple风格文件：Charlie Hills以Claude重用品牌视觉规则，建议REA提取其他品牌

分类：应用与客户端 · REA
记录日期：2026-10-21
阶段：待验证

2026年10月21日18:31:45（北京时间），Charlie Hills（@charliejhills）介绍把参考网页整理成Apple式风格文件，再交给Claude Code生成自己网站的流程。目标是减少Claude建站时的视觉不一致：先提取可复用风格规则，再只用该文件约束各页面，而不是复制Apple标志。作者称整理用了九分钟，并建议用REA为其他品牌制作类似文件；帖子没有明确证明他这次Apple风格提取实际使用了REA，因此这里只把REA归于他推荐的工作流，不补写其分析步骤。

十步流程包括让Claude先问六个问题、选择搜索词、提供真实内容、从风格文件建页、加入滚动效果并保留文字标题、允许AI爬虫、运行22项站点检查和Lighthouse，再部署Vercel及提交sitemap。作者声称自己的各页通过全部22项检查，且ChatGPT曾将其About页列在首位。没有取得检查项目、分数、日志、搜索问题或可复查的曝光记录；这些不证明视觉保真、SEO提升或模型推荐可重复。九分钟也不是完整建站工时或受控效率比较。
