# 录屏编辑器：作者撤下 REA 版本，改用 Claude 与 Electron 从零开发

分类：应用与客户端 · REA
记录日期：2026-10-20
阶段：进行中

10月20日18:08（北京时间），Yıldız Dikme（YildizDikme）报告，已把此前用 REA 开发的应用 GitHub 仓库和 YouTube 视频设为私有。作者称研究许可证后，改用 Claude 与 Electron 从零写录屏及编辑应用，这一次不使用 REA，计划完成测试后免费分享，也用于自己的剪辑；其比较对象价格约100美元。

这是具体项目方向和发布计划的变化，不是许可证违法已被证实，也不是宣布新应用已经公开或功能等价。帖中未命名旧参考产品与仓库，不把它合并到另一作者的 Screen Studio 复刻；原帖补查确认作者身份但没有补出公开代码。本合集未测试新版本，旧 REA 分析的范围也未知，按进行中转向记录。
