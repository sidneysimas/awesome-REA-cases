# Claude Design：把设计功能接进 BaoCut

分类：应用与客户端 · 未确认使用 REA
记录日期：2026-10-12

BaoCut 原本是宝玉开发的视频剪辑 Agent。作者在研究 Claude Design 后，将设计 Skill 与前端功能接入 BaoCut，使本机的 Agent CLI 能选择 design skill，提供公开代码提交。作者指出，仅作为独立 Skill 不能支持编辑、修改和标记，因而先做产品内集成。帖子没有明确说明这次是否使用 REA，也没有证明完整恢复原产品能力。

2026-10-13 的第三方转载帖称，Claude Design 的混淆代码由 REA MCP 辅助拆解、再由 Claude Code 重写，Design 和 Slides 已进入开源 BaoCut；帖中还转述了通过 Slides 生成效果相近 Skill 的思路。这不是原作者的直接确认，本次未核验转述或实现，不据此改变 REA 使用确认，也不代表完整复制 Claude Design。
