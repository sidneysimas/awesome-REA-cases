# GR Viewer：用相机固件模拟器解除手动调试瓶颈

分类：硬件与设备互通 · 未确认使用 REA
记录日期：2026-10-18
阶段：待验证

10月18日14:48（北京时间），@im_xiaoxiao（Xiao）说，自己多年未继续GR Viewer App，是因为连接相机调试总要手动操作，太费时间。现在将GR各个固件交给帖中写作RAE的工具，配合Ghidra研究API和逻辑，做了GR simulator，希望把App开发测试交给AI。他说前一天、即10月17日，时隔数年重新提交了GR Viewer新版本。

补取原帖确认作者与措辞。原文写RAE，不静默改为REA；可能相关但没有足够材料确认工具身份。作者所称所有API和逻辑是自述，没有相机型号、固件版本、模拟器源码、API清单、测试矩阵或商店提交记录，不能确认完整覆盖、真实设备兼容或新版本获审通过。这里关注模拟设备行为以减少硬件在环的手动测试，而非宣称恢复整款相机源码；未运行固件或独立复现。

10月18日候选快照1赞、101浏览、1转发；前一天提交新版本为作者报告，不是商店审核验证。
RAE为来源原拼写；REA身份、所有API覆盖和设备兼容未确认。
