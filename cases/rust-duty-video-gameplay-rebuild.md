# Rust Duty：从《现代战争》视频重建玩法，不反编译

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-16
阶段：进行中

Rust Duty作者把研究问题写得很明确：LLM能否仅从视频提炼玩法，而不是反编译游戏。他提供MW2019、2022、2023及帖中称MW4的动画和玩法视频，报告过去一周使用两个OpenAI Dots、Claude与Grokbot，实现Wgpu渲染器、解析遥测以改善FPS、默认光照及基础UI。武器和手模型是其此前为Arma项目自行购买的资产，作者称没有用这些模型进行AI训练。按从可见行为重建的进行中项目收录，不写成恢复原游戏源码或已经还原全部玩法；没有性能数值、视频到规则的核验或独立运行。

10月15日来源；工具与视频代号沿用原帖，素材授权为作者自述。
