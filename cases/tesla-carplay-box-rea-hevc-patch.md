# Tesla CarPlay盒：Claude、Codex与REA将JPEG路径改为HEVC的报告

分类：硬件与设备互通 · REA
记录日期：2026-10-24
阶段：待验证

2026年10月23日21:37:14（北京时间），半杯拿铁（@vibelatte）称此前未研究过自己的Tesla CarPlay盒固件，交由Claude、Codex与REA拆解，寻找瓶颈并打补丁。作者报告原路径是模糊的30fps压缩JPEG，修改后直接接收手机原生HEVC，完整分辨率、约60fps、2ms解码。

作者称代码完全开源，可从盒子的网页管理界面安装；原串回复仅给短链接。本次核对原串，但未取得可固定核验的补丁仓库、型号、固件版本、帧时间测量或延迟定义，因此“2ms”仅为报告的解码时间，不能写成端到端延迟。也不推断适用于所有Tesla、CarPlay盒或固件。未安装、执行固件或独立验证画质与帧率，按具名用途的待验证改造报告收录。

来源2026-10-23 21:37:14，北京时间；补充回复21:37:44。
30fps、约60fps及2ms为作者报告；未独立测量，2ms不是整链路延迟。
