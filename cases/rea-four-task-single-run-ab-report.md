# REA 四任务对照：OBS 噪声门、Android 地下城与支付提示词的单次实验

分类：算法与功能重建 · REA
记录日期：2026-10-21
阶段：分析测试

2026年10月21日07:30（北京时间），varun bhardwaj（varunPbhardwaj）汇总四个实验，想区分 REA 工具接线与模型能力：小程序、真实 OBS noise gate、仅有编译包的 Android 地下城游戏，以及支付脚本。前三项作者均报告有／无 REA 都为20/20；地下城结果据称对照真实游戏，REA两次搜索定位代码，模型指出反编译器三处错误。

支付项不是同样的有无工具比较，而是同一AI使用两个提示词：一个重复扣费400单，另一个1000/1000。不能把这当真实商户事故，也不能把不同实验条件的得分混在一起。作者称 REA 在这些例子省时省费13%—17%，没有改变结果，并明确每个条件只跑一次，是案例研究而非基准。

补查两个原帖确认10月20日12:04的往期待补审候选是同一作者的20/20与支付前帖，因此保留为历史来源，不作为本窗口新结果。尚无游戏名、样本构建、模型版本、逐例输入输出、计费明细或日志可复算；不能推出REA无用、模型普遍等价或任何任务都能恢复。本合集未运行样本。
