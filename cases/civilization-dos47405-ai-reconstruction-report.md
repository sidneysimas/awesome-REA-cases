# 初代文明 DOS 474.05：AI 辅助 C 重建与四字节差异的转述

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-20
阶段：待验证

2026年10月20日23:22（北京时间），Xiao Tan（tvytlx）转述对1991年初代《文明》DOS版的重建：使用 OpenAI、Anthropic 与 Google 模型从二进制恢复 C，再用 Microsoft C 5.1、MASM 5.10、LINK 5.01 对照474.05版 CIV.EXE。帖子一面说逐字节一致，一面保留四字节差异，并将差异解释为当年链接后补丁的推测；本记录采用有差异的保守描述，不确认整体哈希相同。

转述明确归功于前人 OpenCiv1，承认其代码可能在模型训练数据中，变量名、注释和部分类型是推断，不能称找回原始源码。另称作者编写游戏内部系统技术书。目标是可读重建与历史实现研究，不是《文明VI》的AI策略改造。

补查原串确认转述者身份，公开搜索找到 OpenCiv1 既有项目但未定位该474.05重建的可核验代码与比对日志。没有执行编译、哈希对照或游戏测试，也未核实补丁成因和模型具体分工；字节匹配、书籍与三家模型参与均保留为来源说法，REA未明示。
