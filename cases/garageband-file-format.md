# GarageBand：研究文件格式，用现有乐器自动作曲

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-12

GarageBand 是 Apple 的音乐制作软件。Anshu 为制作 The Context Windows 的音乐视频，让 Claude 利用 Mac 上的 GarageBand 乐器作曲；作者称 Claude 为此逆向了文件格式。最终帖子展示音乐视频，整条流程还包括 Blender、图像生成和本地人声模型。文件格式分析是其中一个具体环节；没有公开详细格式规格，24 小时是完整视频流程的作者工时报告。
