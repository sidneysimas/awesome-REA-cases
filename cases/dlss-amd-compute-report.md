# DLSS：重实现计算着色器以在 AMD 显卡运行的报告

分类：算法与功能重建 · 未确认使用 REA
记录日期：2026-10-12

DLSS 是 NVIDIA 的游戏画面重建技术。MisterSpace3 在相关线程中称 AI 逆向并重实现它，使其以普通计算着色器在 AMD GPU 运行。背景中的 DLSSNR-AMD 仓库确实公开 Vulkan 实现，报告仅在 RX 9070 XT 测试，Windows 仍为实验预览，且不分发原模型权重。但本轮未确认评论指向这一确切仓库，README 也未说明 AI 开发贡献；因此保留为有明确互通用途的待验证报告，不归因全部公开成果给 AI。
