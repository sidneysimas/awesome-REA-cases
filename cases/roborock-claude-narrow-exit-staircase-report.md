# 楼梯下的石头扫地机：Claude辅助研究遥控指令，让机器人自己钻出窄口

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-24
阶段：待验证

2026年10月24日20:17:00（北京时间），Xiao Tan（@tvytlx）转述一位把石头扫地机放在楼梯下的用户：出口只比机身宽几厘米，每次清扫前都得用官方App摇杆手动开出来。对方据称花一个晚上让Claude Code研究并自动化这段出入流程，人站旁边观察并报告碰撞，Claude负责写代码、读日志和测试。

转述称研究发现App所用的一套未公开遥控指令，进入遥控模式约前5秒命令被忽略，离座后机器人会自行转180度。最初遇阻向右避让会撞楼梯柱；定位漂移与窄口余量接近，固定路线不可靠。最后使用卡住就倒退几厘米、从最近角度开始左右轮流尝试的策略，称连续10次驶出并回充均成功。树莓派运行Home Assistant并接Google Home，触发后自动出窝清扫，异常则放弃回充。

这是Xiao Tan的二手报告，未定位原作者或取得原研究链接；扫地机型号、固件、协议记录、源码、日志与10次测试条件未给。约5秒、180度、一晚和10/10均来自转述，不代表所有石头机型或普遍安全性，回充失败处理也未验证。REA没有被提及。目标是窄口机动自动化，不与已有Roborock家庭云重建合并。本合集未连接设备、发遥控命令或运行实现，状态保留unverified。
