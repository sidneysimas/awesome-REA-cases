# Eidolon：多 Agent 从演示二进制到 Rust 的对照报告

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-18
阶段：待验证

2026年10月17日22:07—22:08（北京时间），Rovshan（@mrboldpineapple）报告把一个64 KB级demoscene演示程序的.exe交给AI，从解包、提取着色器和动画曲线、恢复音乐合成器到Rust重写，测试前沿模型能否端到端逆向。续帖把原目标称为Poo-Brain的Eidolon，并称其为Revision 2017 PC 64k第一名；作品归属与获奖信息在本次未另核实。

作者称由一个协调Agent分派任务，工作Agent负责解包、合成器恢复、Rust移植及逐帧SHA-256检查；列出GPT-6 Astra、GPT-6.1 Sol与Claude Opus 5.5，约760M tokens。作者报告约40小时完成，27,000帧和每个音频采样均与原版一致，体积从60,928降为48,128字节，称缩小21%。这里的一致是作者所称输出画面和声音一致，不是Rust可执行文件与原.exe逐字节相同；模型名、时间、tokens和数值均保留原帖口径。

原帖有短链，但本次未取得其目标内容，也未取得源码、比较日志、帧哈希或音频记录。不能把这些数字或端到端成功视为独立验证；REA未被提及，未运行目标代码。
