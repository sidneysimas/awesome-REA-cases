# 电水壶互通：REA与Opus的只读优先、现场确认控制提示词

分类：硬件与设备互通 · REA
记录日期：2026-10-24
阶段：待验证

2026年10月24日04:49:28至29（北京时间），vartekx（@vartekxx）先称用Opus 5.5与REA从床上控制水壶，随后发布完整互通提示词。可收录的具体设计是：只研究自有或授权设备的官方应用、固件或用户提供材料，先确认型号、版本、手册和授权，等待人工批准后只读分析，判断真实存在的是本地还是云端接口、配对流程与消息格式，再决定是否制作状态、温度、设定温度、启动和停止五项功能。它没有提供已填好的型号或任何真实协议发现。

提示词要求优先官方API或Matter、HomeKit、MQTT等受支持标准，其次才是官方应用实际使用的授权本地接口；每项结论附文件、符号、日志、trace或截图，分别记录事实、观察、推断、未知与下一项测试。最小只读请求要与物理状态核对，无安全接口就停止，不发明绕过。连接器默认dry-run、仅允许精确设备、依据手册限制温度与时长、断线安全失败、不自动重试加热、保留本地日志并要求单元与集成测试。停止操作不增加确认门槛。

最重要的限制是不得刷固件、提取凭据、绕过配对或温控、防干烧、自动断电等保护；启动前机主必须在现场，每次明确确认水量和闭盖，模糊、过期或缺少状态回读即取消。80摄氏度是语音请求示例，不是某设备已经验证的温度。正文的卧床控制宣传不能覆盖后文现场值守约束，也不证明真实水壶安全加热。没有代码、设备响应、测试结果或独立复现，所有保护都是设计要求而非验证通过；按互通工作流idea收录，本合集未连接或启动设备。
