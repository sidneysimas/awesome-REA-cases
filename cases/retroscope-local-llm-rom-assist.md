# RetroScope：用本地 LLM 辅助查看 ROM 指令引用

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-17
阶段：进行中

2026年10月17日13:44（北京时间），なごみ（@141_80_call）报告正在实现本地 LLM 分析助手 RetroScope。具体流程是把断点时的寄存器、ROM 和指令等信息交给 Python，挑出引用目标地址的其他指令，帮助分析已有程序中的地址关联，而不是只靠模型猜测。作者明确说当前只能搜索绝对地址，精度还不够，并提到 Ghidra 类工具作为对照。
