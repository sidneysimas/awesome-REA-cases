# 2014 年 Samsung TV：Claude 研究加密遥控协议，经 PIN 配对控制旧电视

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-19
阶段：待验证

10月19日11:13（北京时间），tezarc（@tezzarc）报告把一台12年旧、2014年的非Android三星电视交给Claude Opus 5.5与Claude Code控制。其列出的实际步骤是发现局域网电视、弄清加密遥控协议、使用电视屏幕上的PIN配对，然后发送真实遥控命令。目标是通过自然语言替代手持遥控器，让旧设备继续使用。

作者明确说没有固件破解。补取原帖确认作者和视频附件存在，但本合集未观看视频或实测命令；doing ANYTHING不扩写成任意应用、刷机或所有电视兼容。未取得准确型号、协议实现、代码、配对日志与响应对照，也未确认REA。不与Aswin DG另一台三星电视网页遥控器合并，两个作者的操作不能互作独立复现。
