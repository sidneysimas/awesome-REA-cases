# Linux cal：从无符号程序追出 1752 年日历切换

分类：应用与客户端 · REA
记录日期：2026-10-15

发帖者报告使用 OpenCode、Ghidra 与 REA 检查 Linux 的 calendar 命令，在没有函数名的 stripped binary 中定位到 1752-09-02 的硬编码切换规则；帖子称约 1.5 分钟找到位置，分析结论附有证据，且 AI 标示未追踪部分。作者随后自述切换国家或使用 Julian calendar 时，9 月缺失日期会恢复。此为帖子中的分析与手动测试报告，尚无独立复测；未声称重建整个程序。
