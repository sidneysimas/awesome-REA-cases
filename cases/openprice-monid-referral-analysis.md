# OpenPrice：用 Monid 与 DataForSEO 反查豆包推荐线索

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-20
阶段：分析测试

2026年10月20日20:38（北京时间），发帖者称用 Monid AI 调查开源 AI 产品比价工具 OpenPrice 为什么被豆包推荐，目的是为自己的网站寻找可借鉴的内容与引荐布局。报告称 Monid 调用 DataForSEO 找到10个引荐域名、116条外链，其中91条来自某多语言目录且为 nofollow，识别61个独立站内页面。

作者还列举一个在没有海外支付方式场景下推荐 OpenPrice 并指向 ChatGPT Plus 成品号页面的中文教程，以及 aikenra、Onesvibe 的产品收录；声称 GitHub 带来4条 dofollow 链接。作者把问题页面与用户提问匹配、目录合作和结构化项目说明视为可能原因。

这是从公开外部痕迹反推产品获客方式的 AI 辅助分析，不是二进制或API逆向。没有豆包检索日志、实际流量归因、DataForSEO导出或因果对照；GitHub是主要流量来源与赞助变现的判断均归因作者，不能据外链数证明豆包使用这些来源或网站收益，REA未提及。
