# Mujina矿机固件：Aadhi确认Claude参与开发，补充Canaan调频背景

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-25
阶段：待验证

2026年10月25日23:17北京时间，Aadhi Maalaven（@unknown_aadhi）回复Marc Fresa与skot，确认Claude帮助制作了所讨论的固件。补查父串：skot在当天10:53介绍Mujina开源固件用于解放更多挖矿硬件，Marc随后猜测它由Claude Code制作，作者才作上述确认。这里可识别具体项目与AI参与，不把旁观者猜测当模型版本证明，按相关硬件重建报告收录。

10月26日05:15的补充回复中，Aadhi称已有简单自动调频器，并解释Canaan ASIC与Bitmain不同：有四个PLL时钟，各SHA256引擎按温度与错误率选择PLL，原厂各PLL相差20MHz。该回复提供作者研究的控制背景，不证明调频收益。另一回复关于竞争者损坏Z15 Pro的传闻不作为本项目测试。

候选及父串未给目标矿机型号、原固件恢复方法、Claude会话、代码定位、算力、功耗或稳定性验证；没有确认REA使用，也没有独立运行固件。补充串仅识别项目与技术背景，日期区别于原候选；本条不是盈利、节能或安全调频认证。
