# Maxwell：不改源码、运行时优化机器码的项目转述

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-20
阶段：相关项目

10月20日16:27（北京时间），Han（Hh_Boulevard）介绍 doubleAI 的 Maxwell，称其被称为 Code Execution Model：源码保持不变，在程序运行时修改底层机器码，目标是让已有数据处理及推理程序更快，并声称每一步都有形式化等价证明。帖子把它与生成新源码的编程助手区分开，是与AI辅助二进制理解及改写相邻的项目，而非REA案例。

该帖转述厂商声称数据管道加速超过38倍、推理kernel超过4.5倍，并明确说Ctech报道这些数字未独立验证。作者说产品前一天发布，但本合集未核对厂商发布日期、原报道、样本或证明检查器；日期和倍率不作为已核验研发事实。没有执行优化代码或证明，亦不能把不改源码等同于任何程序都行为不变。
