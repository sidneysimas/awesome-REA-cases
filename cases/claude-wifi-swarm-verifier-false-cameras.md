# 家庭 Wi-Fi 的64个 Claude Agent：验证器否决9个摄像头猜测的自述

分类：硬件与设备互通 · 未确认使用 REA
记录日期：2026-10-21
阶段：待验证

2026年10月21日21:35（北京时间），Vexo（@Vexo200）描述让64个Claude Code Agent检查家庭Wi-Fi，用中间验证器拒绝没有抓包支持的发现。他称覆盖41台设备，11分钟追踪1206连接；电视一天联系广告追踪2940次并被关停，19美元插座每90秒访问海外服务器，打印机仍运行2019年固件且9100端口对全网开放。这里的全网没有外部探测位置，不能解释为公网暴露。

标题所谓发现9个隐藏摄像头在正文被作者自己否定：烟感、婴儿监视器和音箱等猜测拿不出一包视频，9项都在verify.log里被否决，不是销毁了9台摄像头。没有视频包也不证明设备绝不含摄像头。作者还声称某酒店烟感故事被Community Notes纠正；本合集未查到对应注释，不能据此替其他候选作真假定论。
