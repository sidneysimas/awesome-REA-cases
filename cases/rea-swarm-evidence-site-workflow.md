# 常驻 REA bot：把认证与广告问题整理成可点击证据站点

分类：应用与客户端 · REA
记录日期：2026-10-18
阶段：待验证

10月18日21:13（北京时间），作者说已把REA bot作为bot swarm的常驻成员。具体问题包括App如何向服务器认证、为什么DNS屏蔽后广告仍加载；其他bot也能把问题交给它。调查结果按结论附证据与置信度，并整理成小型可点击站点，而非只给聊天长文。

作者描述不可信目标放在可丢弃Linux机器、Apple Silicon目标交给Mac，反编译在临时隔离网络容器中进行。文中验证器密钥、时间计数器与HMAC例子明确来自REA文档，不当成作者新发现；本地分析也不代表模型服务商收不到工具结果。没有具名认证目标、广告样本、站点、容器配置或运行日志，无法验证隔离效果和调查准确率。按使用者工作流自述收录，不宣称成功重建软件。
