# Decompwtf：让 AI Agent 重建游戏 C/C++ 并对照机器码

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-16
阶段：相关项目

10月16日 @Pirat_Nation 介绍 Decompwtf，称它让 AI 编程 Agent 从游戏编译代码恢复 C/C++，再编译结果并与原二进制比较机器码，以加速游戏保存和既有社区反编译工程，而非只重画界面。帖子列出 N64、PS1、PS2、GameCube、Wii、GBA 和 DS 目标，并称本地运行、不需账号或上传游戏数据。这是来源描述的工作流和范围，不表示任意游戏都已字节匹配。本轮补查原串与公开 GitHub 仓库名检索，未取得可确认的源码、匹配日志或完成游戏清单；开源、隐私和兼容性仍是来源说法，本合集未安装或运行。

10月16日候选快照：1,331赞、30,869浏览、116转发；热度不是验证结果。
