# Greenlight 影片接口：AI 查询字段后，用非法值测试真实验证行为

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-16
阶段：分析测试

Greenlight 构建记5-6讲述为一款未具名、预览阶段的影片模型接入时长与画幅设置。官方资料薄、外部文章过时，Claude 试了十几个参数名，花半天都只得到 unknown field。作者称改问带搜索佐证的平台内 AI，一次花五美分得知秒数与比例位于 response_format，任务类型在 video_config；同时获知文字生影片、图片生影片、参考图生成、编辑与延长五类任务，以及3至10秒范围。它不是仅让AI生成示例代码，而是围绕黑箱接口逐项观察。

作者随后输入99秒，预期拒绝却被接受并实际生成，花了一美元，于是在本地请求发送前加上3至10秒范围检查。之后外部通用 Gemini 又给出两引擎皆支持某功能的错误例子，经非法值测试推翻；某些引擎要轮询后台作业才看到验证结论，首次收到请求不等于接受参数。具体模型、接口版本、币种说明及完整请求响应均未公开，文中还说登场人物使用化名，因此字段布局、价格与范围只作为该作者这次接入的报告，不能推广为某个已知厂商的API规范或保证所有“平台AI”可靠。未见 REA，未独立调用服务复测。

10月16日候选快照：0赞、264浏览；半天、五美分、一美元及3至10秒均为作者叙述。
