# Harness Studio：自上而下重建 Claude Code Desktop 的开源项目自述

2026年10月21日10:25（北京时间），Vignesh（@vigneshv1cky）称逆向Claude Code Desktop并把每项功能带到自己的项目，采用top-down路线而非REA。此前补查完整串识别项目为Harness Studio：面向macOS与Linux的开源编程桌面，让用户选用自己的模型供应商与密钥。当天05:59推广回复作为往期补审合入，更早03:36介绍只用于背景，不是本轮新发布。

2026年10月23日02:26:43的新候选由同作者发布，补充说明以DeepSeek harness为基础逐项增加功能，目的在于保留喜欢的桌面工作流，而不被单一模型供应商或订阅绑定；宣称可使用Claude、OpenAI、Gemini及本地模型的自备API key。这里区分基础项目与重新研究的桌面目标，不将DeepSeek基础误当原版Claude源码。

仍未取得可核定的仓库版本、实现比对或测试输出，不能把“每项功能”写成已验证等价、任意供应商兼容或已独立确认cleanroom。AI模型接入是明确用途，具体逆向使用了什么模型未交代；作者早期明确不使用REA，最新帖未推翻此说明。保留other-ai进行中项目，本合集未运行桌面软件或访问API key。
