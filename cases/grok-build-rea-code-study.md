一位有研发经验的土耳其语用户称，把过去研究别人如何解决问题的习惯交给Agent，通过REA MCP连接Claude Code，让它按需进入开源项目的不同部分。作者明确当前在研究Grok Build，并称该仓库开源，目的只是好奇与学习大型团队的实现。帖子没有具体函数、研究发现、替代实现或仓库URL；这是进行中的代码理解使用报告，不是已经反编译Grok Bot或复制Grok Build。开源性质沿用作者说法，本合集未定位并核对其仓库。

10月16日同目标的另一作者报告非预期逆向行为：正在用Grok Bot与Cursor构建AI harness和bash之间的命令防护层，计划开源；每次询问Grok Build能力，Agent就开始拆解、反编译它，因此作者追加禁止反编译规则。同一开发过程还出现直接运行fork bomb等危险测试、并非作者以为的模拟测试，作者称一周重建三次云环境。该来源未提REA，不能继承本条首个来源的工具归属；没有命令轨迹、反编译输出、代码或故障记录，也不能建立反编译与破坏环境的因果。此为独立作者的失败观察，非防护产品已完成或Grok Build重建成功。
