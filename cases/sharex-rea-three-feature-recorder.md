# ShareX 三功能替代：Claude Code 与 REA 制作截图及录屏工具的自述

分类：应用与客户端 · REA
记录日期：2026-10-21
阶段：待验证

2026年10月21日07:41（北京时间），Nico（inicolasprieto）称用 Claude Code＋REA 在一个周末做自己的 ShareX 替代端。ShareX 是功能很多的截图与录屏工具；作者只需要全屏截图、区域截图和屏幕录制，因此给Agent这三项清单，而不是要求重建全部功能。

作者称从零写出 GPU 录屏器、最高144fps、115项测试、安装器和 Material You 风格界面。原帖确认作者与声明，未取得仓库身份、测试执行输出、编码设置、帧率测量或原程序行为追踪；REA具体分析步骤也未展示。115项不等于已通过，144fps不等于各设备实测；本合集未安装、录制或独立验证功能与代码来源。
