# Kindle：Claude Code 辅助越狱、Tailscale SSH 与 Readeck 文章同步的转述

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-19
阶段：待验证

10月19日12:51（北京时间），@keyiLeYi 转述一个Kindle工作流：USB连接电脑，交给Claude Code越狱，移除亚马逊自带内容，安装Tailscale以便SSH登录；照片中的KOReader正在更新。阅读用途是把在别处看到的文章保存到Readeck，经家中服务器同步，Kindle联网后即可读到。

这是第三方文字说明，不是该发帖者发布的完整研究记录。其明确指出Kindle越狱早已有之，回复称上一个漏洞7月被补；准确设备、固件、采用哪种旧方法与prompt均未给。本合集没有独立核实该漏洞时间，也不推断AI发现新漏洞、任何固件均可越狱或删改无风险。没有源码、解锁日志、联网同步对照或硬件测试，照片描述不升级为验证。REA未确认，与Android/微信读书或ZenOS/EPUB界面是不同用途，不能混成同一项目。
