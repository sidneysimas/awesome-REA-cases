# Computer 接入 REA：Figma 等五款应用功能重建演示

分类：应用与客户端 · REA
记录日期：2026-10-17
阶段：待验证

10月16日23:42（北京时间），Computer 官方账号 @AskPerplexity 宣布将 @morluto 的 REA 作为 skill 接入 Computer，并称可在没有源码的情况下研究应用、构建可工作的版本。候选直接展示 Figma 方向：图层、auto-layout、登录、跨设备同步和多人编辑。补读同作者23:43的连续回复，另有 LibreOffice Calc 的单元格、公式和联动图表；Photopea 的图层、蒙版、调色和可编辑文本；Harvey 的合同检索、版本比较、按规则标记条款与来源引用；Audacity 的音轨剪裁混合、音量、淡入淡出和 WAV 导出。五项是同一次产品发布的演示合集，不是五个独立复现。

官方称演示仅限时可试，使用 /reverse-engineer 的任务免费到10月31日、每用户最多10,000 credits；这些是当时促销口径，不是永久免费承诺。正文及演示链接未提供本合集取得的分析日志、源码、原版对照或持久服务保证。没有验证多人协作、真实文件兼容、公式覆盖或合同分析正确性；官方发布确认平台的功能主张，不证明完整复刻或安全上线。未执行演示、注册服务或处理真实合同与账户。

10月17日11:45，一位读者称登录 Figma 方向的 Assemblage 后，只看到部分核心能力，很多功能未实现；这是用户观察自述，不是完整功能矩阵或本合集独立试用。其推测开发方担心诉讼而故意停下，没有证据，不采纳，也不据此宣称个人可完整复刻。

候选快照（10月16日）：25赞、2,317浏览、4转发；与补读时变化的指标分开。
官方功能演示，未经独立运行或原版等价测试；10月31日与10,000 credits 是当时活动限制。
