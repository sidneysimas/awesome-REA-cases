# IDA 9.5：Hex-Rays发布含MCP／Assist与调用图递归反编译的版本

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-27
阶段：相关项目

2026年10月27日03:56:49（北京时间），Hex-Rays SA（@HexRaysSA）发布IDA 9.5消息。补查原帖确认官方署名及全文：新增Android Dalvik、Infineon TriCore和Qualcomm Hexagon反编译器，提供IDA MCP与Assist供AI驱动逆向，支持沿调用图递归反编译；IDA Home所含云反编译器从2个增至11个，官方称价格不变，有效许可用户可从Download Center下载。

目标是将AI Agent接入成熟的二进制分析工作台，扩展可分析架构与跨函数阅读范围。它是公开工具版本公告，区别于基线第三方IDA Assist rc15的SQLite镜像实现和个人nullsub改名实验，不将这些不同项目合并。没有指定AI模型、样本、质量指标、运行时验证或独立对照；不认定全部三种新反编译器都是AI实现，也不把11种云服务数量当已验证平台数。

按related-project收录官方发布，未读下载内容、安装IDA、运行MCP或验证许可价格；REA未提及，发布功能仍归因于厂商。
