# Uncharted 1–3：Claude 逆向与 Windows 原生版的转述

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-16
阶段：待验证

一则引用帖称《神秘海域》（Uncharted）1、2、3已可在Windows PC游玩，描述路线为用Claude逆向，将PS4代码转到Vulkan，做原生Windows构建并共用一个启动器。帖子还列出60/120 FPS、DLSS、FSR、帧生成以及键鼠和手柄支持，主观评价性能很好。它提供的是具体三作移植的传播报告，不是源码或可重跑验证；本次没有取得仓库、构建和硬件测试，不能确认这些功能已经实现，也不能把帧率写成普遍性能。未确认REA使用，不提供游戏文件或推断发行授权。

10月16日候选快照：5赞、1250浏览；非独立复现。
