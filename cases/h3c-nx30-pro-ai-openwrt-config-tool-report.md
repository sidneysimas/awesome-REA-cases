# H3C NX30 Pro：AI审读既有配置工具、移植Python并协助刷机的自述

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-23
阶段：待验证

2026年10月23日11:38:34（北京时间）的作者自述，目标是将H3C NX30 Pro从原厂V100R010固件改为OpenWrt，以满足家庭网络用途。作者称自己没有编程或拆机，只接线、按键、输入命令和拍照，由未具名AI指导。该过程不是AI独立发现新漏洞：作者明确说AI找到ArtiSheng的同版本记录，其来源是茶栗（@chariri）的文章，并审读两套已有工具。

据自述，AI将开源Rust工具移植为Python、生成配置修改脚本，借设备原厂配置恢复路径取得root shell；还要求备份10个闪存分区、保留原厂BL2、核对引导与正式固件哈希。在临时TFTP传输反复超时后，AI结合代码和屏幕日志将问题归于Windows防火墙处理协商端口，作者报告9.1MB随后在1.2秒传完，凌晨05:21看到OpenWrt 25.12.6界面。这里的时间、版本、数量、传输结果均为作者报告，不是本合集测量。
