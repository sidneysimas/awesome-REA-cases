# fowlbrowser：让 Claude 等 Agent 使用现有 Chrome 登录态

分类：应用与客户端 · 未确认使用 REA
记录日期：2026-10-12
阶段：待验证

champi 在本周期询问 argofowl 的新浏览器扩展是否来自此前计划的 Codex 扩展逆向。对应作者发布帖与 README 介绍 fowlbrowser：通过 MCP、本地消息桥和扩展让 Claude 或其他 Agent 使用现有浏览器标签页和登录态，可在后台工作，并把登录、付款交还用户，提供公开仓库。目前仅支持 macOS，Chrome/Helium 已测试，其他 Chromium 浏览器测试较少。具体互通项目已有发布，但评论的逆向归因仍是问句，不能写成作者已确认恢复 Codex 协议；性能比较仅为作者的小样本报告，本合集未运行扩展。
