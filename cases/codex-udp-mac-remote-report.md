# 极米 Z7X：Codex 研究 UDP 与蓝牙开机，做 Mac 菜单栏遥控器

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-19
阶段：进行中

10月19日00:24（北京时间）的候选回复转述Codex逆向UDP、制作Mac遥控App并成功右移选框。补读其父帖：@aifomo602于10月18日19:46报告家中极米Z7X遥控器常找不到，遂让Codex研究协议、做常驻Mac菜单栏的App。两设备同Wi-Fi下，UDP向右指令据称使投影选框移动；开机则采集iPhone官方App蓝牙广播，解析设备标识与iBeacon信号。

作者说曾遇到Mac显示发送成功但投影不亮，改由独立原生前台助手发信后实测开机，静默发送体验仍优化。语音音量、睡前关机与其他家居接入只是后续设想。父帖早于当前窗口，仅作归属和技术背景补充，不是本轮新候选；没有源码、抓包或独立设备测试。不能把发送成功等同接收成功，也不与既有红外对焦研究合并。未确认REA。
