# 吉他效果器：先模拟原固件，再对照独立 C++ 算法库

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-17
阶段：待验证

10月17日13:33（北京时间），@RealYDT 转述吉他效果器厂商 valdiorn 的经历。补查 Hacker News 找到其原评论，发表于10月15日15:19:19 UTC（北京时间23:19），早于本轮候选窗口，仅作为追溯来源。valdiorn 称自己经营小型专业音频公司，正在制作类似 Eventide H90 的多效果处理器，希望提供混响、延迟、合唱等算法；H90 是产品目标，不是已证明被反编译的对象。

他自述过去72小时研究了三家主要竞争者的产品，包括 Strymon Big Sky，并称 Opus 5.5 用一个提示、三小时完成相关反编译。方法是先让 Claude 构建模拟器运行原厂固件／ROM，避免只是生成听起来相似的效果，再转为独立 C++ 库并与模拟器结果比较。他称全部试听很好；Lexicon 224 部分复用了 Claude 找到的一周前公开在 GitHub 的既有代码，另称整个 Ursa Major 产品线只需20分钟。这些时间不能相加成可复现的统一项目工时，也不能把复用代码写成模型独自恢复。

原评论确认了转述的基本内容，但未公开模拟器、C++ 库、固件版本、测试向量或数值／听音对照记录；未核实所指 Lexicon 仓库。没有证据证明位精确、完整覆盖竞争者产品或已上市。作者同时表达担忧，并说不会把竞争者算法装盒转售；不能将研究自述写成已获商业授权。本合集未运行固件或代码，未确认使用 REA。

原评论日期：2026-10-15 23:19，北京时间；本轮候选为10月17日转述。
