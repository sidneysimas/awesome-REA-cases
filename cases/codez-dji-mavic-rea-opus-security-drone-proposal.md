# DJI Mavic安防无人机：Codez提出REA／Opus与官方SDK的手机端跟踪方案

分类：硬件与设备互通 · REA
记录日期：2026-10-27
阶段：待验证

2026年10月27日00:55:21（北京时间），Codez（@0xCodez）称以REA和Opus 5.5逆向自己的DJI Mavic并改为家庭安防无人机。补查原帖确认署名与全文。背景是家庭警报触发后，让连接遥控器的备用手机承担视觉识别、目标跟踪与控制；作者称无需云端，也不需要目标携带GPS。

正文是一套构建设想：先检查DJI Mobile SDK v5支持名单，不支持就停止、不改固件；以官方SDK写Swift或Kotlin小应用，Home Assistant发通知后人工点击Launch，手机运行YOLO，Kalman filter在遮挡时保持跟踪，再通过10Hz Virtual Stick控制。作者写到不近于8米、到地界停止并升至30米、返航落在停机坪，以及手机保存轨迹、距离和时间戳。这些是帖子方案中的参数与预期行为，不是测量结果、安全认证或可直接执行的飞行建议。

没有给出Mavic具体型号、SDK与操作系统兼容矩阵、REA恢复了什么协议、代码、飞行日志、避障测试或返航验证。官方SDK开发本身不证明固件已被逆向；文中iPhone／Android双平台宣称也未核验。保留为作者宣称已做、但证据主要为步骤说明的unverified方案，不认定演示视频已证明全流程。未运行目标代码、连接设备或执行跟踪飞行。

候选快照275赞、14530浏览、24转发；后续补查热度变化不作为窗口内传播数据。
8米、30米和10Hz是作者所列方案参数，未验证安全性或兼容性。
