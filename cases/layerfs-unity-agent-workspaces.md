# LayerFS：为 Unity 逆向材料节省多 Agent 工作区存储的转述

分类：应用与客户端 · 未确认使用 REA
记录日期：2026-10-21
阶段：相关项目

2026年10月21日21:26，Chasen（@chasen_liao）介绍 LayerFS v1.0.0，称其为AI Agent文件系统：每次Bash调用有独立工作区，同文件冲突拒绝，fork不复制全部文件，并可回到历史步骤。帖子转述某位使用者把Unity游戏逆向文件从400G缩为33G；22:39另一帖补充材料来自8天工程。两者没有给游戏名、原始存储测量或该使用者日志，不能当作两次独立实验。

后一帖还转述作者做Rust数据库引擎任务，30个分支有2.5TB快照、实际占4.66GB，main单分支原本8.23GB。前帖另称10份拷贝占0.31份空间、挂载0.05秒。全部是不同口径的来源数字，不混合成压缩率，也不等于逆向速度或准确率提升。去重、不复制分支等是来源解释；尤其后一帖说明其机制解释来自Grok，不能升级为源码核验。MIT、开源、回滚与冲突保证均为宣传，未取得仓库实现或运行测试。本案只记录用于多Agent逆向工作区的相关工具，没有确认REA参与，也没有执行下载代码。
