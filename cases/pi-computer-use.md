# pi-computer-use：把 Codex 桌面操作接给其他模型

分类：应用与客户端 · 未确认使用 REA
记录日期：2026-10-12

Zane Chee 希望 pi Agent 也能使用 Codex 风格的电脑操作，于是研究 Codex Computer Use 并开源 pi-computer-use。作者展示优先读取 macOS 无障碍树、在支持的模型上回退到视觉的路线，并在后续帖子补充后台模式。它是模型无关的电脑操作工具，未确认使用 REA；演示不意味着所有 App 都能后台控制。
