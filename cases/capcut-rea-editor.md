# CapCut：用 REA + Claude Code 做自己的视频编辑器

分类：应用与客户端 · REA
记录日期：2026-10-13

Mehal Kumar 报告让 REA 配合 Claude Code 研究 CapCut（视频剪辑软件）的功能，再生成自己的编辑器，列出自动字幕、转场、动画和文字，附视频演示。他称约 30 分钟搭建，仍有功能待添加；没有公开源码或系统性导出、行为对照测试。与此前另一作者的转场研究线索不视为同一实现，不称已完整替代 CapCut。
