# COBOL ATM 账本：REA 与多 Agent 重建的明确模拟方案

分类：应用与客户端 · REA
记录日期：2026-10-20
阶段：待验证

10月20日17:44（北京时间），作者借一个流传的旧系统重写演示，描述将同样方法模拟用于 COBOL ATM 账本：REA 把146个旧文件整理为一个规格，Opus 5.5只规划一次，12个Sonnet 5.5 Agent各重建一个模块，再回放新旧行为。目标是讨论较便宜模型分工能否降低旧账本迁移成本。

帖子给出120/120行为匹配、单独Opus 4.85美元对swarm 0.97美元，同时明确写“all simulated”。这些数字是作者模拟叙事，不是实跑账本、真实账单或独立实验。开头24万美元任务变7分钟0.88美元及REA星数也是引述背景，不作为项目成果；没有原文件、规格、代码或回放日志，本合集不验证这些数量，也不把它列作成功金融系统迁移。
