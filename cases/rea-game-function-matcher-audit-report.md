10月17日07:42（北京时间），@xmyttle 转述 REA 博客的三段游戏函数重建接力：GPT-6-Sol 到 GPT-6.1-Sol、GPT-6.1-Sol 到 GPT-6 Astra，以及 GPT-6-Luna-max 分别得到 match；称 Astra 调整控制流图让编译器合并出相同分支。更有价值的是其验收限制：指令比较只有在记录了地址所指内容时才读该值，后续审计发现有函数使用错误常量仍获接受，例如原来加32.0f却改成加1.0f。
