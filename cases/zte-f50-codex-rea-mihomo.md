# 中兴 F50：Codex 与 REA 辅助 root 并安装 mihomo 的设备自述

分类：硬件与设备互通 · REA
记录日期：2026-10-21
阶段：待验证

2026年10月21日11:54（北京时间），Penn（bubbleinpit）说刚购买中兴F50，随即用Codex＋REA将运行Android的设备root，并安装mihomo，报告效果很好。用途是让小型插卡联网设备运行自己的网络代理，而不是已经移植OpenWrt。

作者称F50只能插卡使用，不能中继现有Wi-Fi；认为可刷OpenWrt但root后已有mihomo，没必要改刷。这是作者对设备与替代方案的判断，不是本合集验证的所有版本限制或成功OpenWrt安装。未给固件、漏洞、权限获取步骤、代码、流量测试或恢复记录；本合集未连接设备、root或运行代理，不保证兼容性与安全。
