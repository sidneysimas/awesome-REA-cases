# PS5 安全机制：AI 辅助逆向的传播报告

分类：硬件与设备互通 · 未确认使用 REA
记录日期：2026-10-28
阶段：待验证

PS5是索尼游戏主机。0x0SojalSec称AI在数周内逆向其安全机制，并附越狱商店画面。帖子没有研究者原始记录、AI工具、固件版本或代码，无法确认AI贡献，也不能据此证明整个游戏库均可访问。2026年10月15日另一则第三方报道提到研究者2tonejordy，称他使用LLM重新发现一个已知漏洞，并提及索尼漏洞赏金。这增加了具名线索，但不能确认赏金对应的漏洞与LLM实验是否同一项工作，更不能把报道中PS5模拟器、Linux或Windows项目都归因于AI。

2026年10月28日04:07:10（北京时间），AI观察者（@ppmmzzcn）的AIBase摘要援引IGN称，Jordy借助生成式AI找出高危漏洞，并通过索尼渠道获5万美元（帖子折合约33.4万元人民币）赏金。同帖说明在他之前另有安全工程师先发现漏洞，并研究13.60至14.0固件上的Linux。按既有Jordy线索追加，不另建PS5案例，也不把前人Linux工作归功Jordy或AI。

补查只确认该摘要原帖署名与正文；未取得IGN全文、漏洞编号、原始分析、索尼确认、赏金记录或重现日志。金额、危险等级、固件范围与支付均为二手说法，不能建立AI独立首发漏洞、成功安装Linux或整个主机安全机制已破解的结论。REA仍未知，状态unverified；本合集未操作主机，不提供游戏资产、破解步骤或盗版商店入口。
