# Linux MPTCP：二手报道内部Claude模型研究内核网络竞态链

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-29
阶段：分析测试

2026年10月29日09:33:04（北京时间），Ummon在五目标报道中转述Anthropic的Linux网络栈研究。目标是暴露多路径TCP监听器的内核路径，报道概括竞态导致释放后使用、泄漏内核地址后影响回调控制流，声称达到无需凭据或用户交互的root命令执行。只记录研究层面，不给触发包、利用代码或操作步骤。

补读10月27日官方文章，确认项目自述演示约48分钟取得地址、再五分钟达到命令执行，失败竞态只使握手失败而不使系统崩溃。官方标识CVE-2026-98432，称上游及所有维护中的稳定分支已修复。这些时间不是通用成功时长或性能基准，监听配置也不能扩大成所有Linux系统均远程可达；较早官方文档仅作候选补证。

内部模型未具名且从人工初始提示开始。文章说明协调披露，没有报告在野利用，不据此保证没有攻击者。本合集未读厂商/内核公告、构建或日志，没有运行利用或向设备发包。保留项目分析测试状态，CVE、修复与影响不作独立确认，REA未提及。
