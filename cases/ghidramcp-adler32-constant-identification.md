# GhidraMCP：用常量指纹从剥符号程序识别 Adler-32

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-20
阶段：分析测试

2026年10月20日21:33（北京时间），发帖者演示让 Claude Code 经 GhidraMCP 研究剥去符号的二进制，目标是把匿名函数对应到已知校验和及格式处理，而非重建整个应用。报告称28个MCP工具提供访问，批量反编译170个函数，搜索 Adler-32 模数65521、CRC-32多项式0xEDB88320与gzip魔数1f 8b，46.7秒得到10个候选；再以分块大小5552（zlib NMAX）支持 adler32 识别。

帖子给出遍历反编译文本搜索常量的简短代码与连接示例，但未命名样本、列出函数地址、导出伪代码或给出运行对照。常量是识别线索而非独立功能证明，尤其不能把筛中CRC或gzip常量等同整套解压算法恢复。时间、函数数与准确性均为来源自述，未重跑，未明示REA。
