# 离线 Linux 逆向工作机：隔离 Codex 与私人文件

分类：应用与客户端 · REA
记录日期：2026-10-18
阶段：进行中

10月18日06:41（北京时间），Johan Slåttavik（@JohanSlattavik）说 REA 很有意思，但不愿给 AI 工具自由访问自己的电脑，因此正在搭建一个隔离 Linux 工作机，让 Codex 使用 REA、Ghidra 和 JADX，同时无网络、不能访问私人文件。具体用途是保留 Agent 逆向工具链，又缩小工具对个人主机和数据的访问面。

09:43 同一账号在同串澄清当前架构目标：REA、Ghidra、JADX 运行在隔离虚拟机（VM）内，他通过 Linux 上 VS Code 中的 AI 控制这些工具。补查原帖确认作者和对话与早先记录一致，因此追加到本条，不另建隔离工作台。VM 是计划采用的部署边界，不是本合集验证的安全属性。

方案仍在建设，没有给仓库、虚拟化产品、文件传递方式、Codex 推理连接或隔离测试；具体怎样同时满足无网络与外部控制仍未解释。不能补成已验证的离线模型系统或安全沙盒，也没有报告对具体二进制的分析成功。
