# tolpo：研究Tapo应用协议，经MCP控制设备并显示实时3D住宅

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-29
阶段：进行中

2026年10月29日01:50:01（北京时间），beamnxw转述有人研究Tapo智能家居应用，以Claude Code完成大部分项目和协议研究，再让tolpo通过MCP读取/控制灯、插座、传感器和相机。按设备名猜房间，人工修正布局后显示3D住宅，门磁状态驱动画面中的门，相机点击后显示视频。AI参与研究是该帖的归因，不是本合集对开发过程的审计。

按具名项目补查signerless/tolpo，固定提交07fdd5c81f1f6dc7326cd1cfdc67dc64ba7543a1日期为2026-10-15 04:28:53，北京时间；较早源码用于补充核验，不冒充本窗口新开发。README说明复用python-kasa的KLAP/SSL-AES通信，加C465证书兼容修正，并独立分析官方应用与实物；不是Claude从零发现全部Tapo协议。MCP与HTTP共用核心，使用设备所属Tapo账户，在LAN与设备通信，不代表模型本地运行或图像不会送往模型。

项目列L430C、P115、H200、T110/T310/T300、C225/C610/C465、D230为实测硬件。home_plan文档报告2026-10-12在作者家中测试九房间、18设备、两相机视频、灯开关和布局保存；只是项目自测。大多数扩展写操作只在模拟设备测试，扫地机、门锁、温控阀与防火墙未实测，门锁尚不可用，云账户/共享/Tapo Care等不在本地范围。户型依据英德西设备名猜测、需要人校正，不是自动测绘住宅。

相机图像默认关闭并检查隐私模式；高级安全/生命周期操作有额外权限与确认短语，但短语不是人已同意的证明。原帖串的先只读、先问许可原则是部署建议，不是安全认证。未执行代码、接入设备或独立核验视频/全功能。

候选快照51赞、1037浏览、3转发；源码MIT标识不替代设备或云服务授权。
