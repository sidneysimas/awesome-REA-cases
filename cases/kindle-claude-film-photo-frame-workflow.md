# Kindle 胶片相框：Claude Code 的 USB、照片与 FBInk 工作流

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-21
阶段：待验证

2026年10月21日03:49（北京时间），作者分享据自己 Claude 会话经验整理的具体提示词：把 Amazon Kindle 改成展示胶片扫描照片的电子墨水相框，电脑处理文件，人只在设备上按键，并尽量合并 USB 拷贝。流程要求按 USB 信息、序列号和系统版本选择现有越狱方法；无适配方法便停止，不注销或恢复出厂。

照片处理要求按面板分辨率转灰度、轻度锐化、生成联系表并跳过空片；相框设计为每30分钟换图、无重复洗牌和保存位置，点按显示时钟与 Open-Meteo 天气，支持滑动、长按退出、16灰阶抖动和 FBInk 局部刷新。另要求恢复原界面、处理硬件深色模式、RTC 唤醒与省电回退，并先生成预览 GIF。

这些是提示词的验收目标，不是本合集见到的设备测试结果。作者提醒第11代及之后的 MTP 型号、5.16.3及之后固件需要不同选择；没有设备型号、源代码、GIF 或刷写日志。复用社区越狱和显示工具不等于 Claude 发现新漏洞，也未确认 REA 参与。
