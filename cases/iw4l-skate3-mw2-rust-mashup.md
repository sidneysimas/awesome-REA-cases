# 2010 Rust Rewrite Mashup：在 MW2 地图里玩 Skate 3

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-16
阶段：待验证

本窗口转述介绍2010 Rust Rewrite Mashup，称它基于从零用Rust重写MW2的IW4L，在2009年《现代战争2》地图与Minecraft世界中加入Skate 3滑板玩法。帖子说Windows用户需自有MW2及Xbox 360版Skate 3文件，并称仓库包含AI Agent指令文件及LLM使用声明。它同时强调社区长时间研究Skate 3、创作者约半年制作Xbox 360重编译工具，AI加速的是其上的编码，不能写成一夜自动反编译两款完整游戏。未取得仓库与运行记录，本条为二手报告，也不与Maurice的MW2反编译项目或Universal Modder默认视为同一工程。

10月15日来源；约半年为二手转述工期，非独立核验；未确认REA。
