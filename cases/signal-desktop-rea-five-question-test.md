# Signal Desktop：REA 与 Codex 五个行为问题对照源码的自测

分类：应用与客户端 · REA
记录日期：2026-10-20
阶段：分析测试

10月20日06:12（北京时间），Aakash Gupta（@aakashgupta）称选择开源的Signal桌面应用，让接入REA的Codex回答竞争产品研究问题，再与真实源码核对。他报告五题全部正确，每题3至7分钟；公开正文只给出一个具体例子：可置顶多少聊天及超限会怎样，REA答4并指出服务端可调整限制，没有公开展示超限行为的答案。

作者同时披露一次运行发生完整性错误并超时，Codex绕开REA直接读应用文件后得到与源码一致的答案。因此五题成功不能全部归因于REA，也不是无人干预工具链稳定性证据。作者称服务端可改变80个配置，单凭客户端无法确定账户实际获得的设置或用户实验结果。

同分钟续帖给全文测试和REA仓库短链。本合集补取原帖完整正文以核对归因；未取得文章全文、五题逐题记录、Signal版本、使用提示词或计时日志，没有独立运行测试。335K星与一周增长208K是帖子营销上下文，不作为仓库实时统计或分析准确性的证据。

候选快照21赞、3272浏览、3转发；不是独立评测或复现。
