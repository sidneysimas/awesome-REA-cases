# Wispr Flow：DeepSeek 与 Opus 重建本地听写流程的自述

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-20
阶段：待验证

10月20日16:52（北京时间），Vraj（vraj_ai）称逆向 Wispr Flow，并用 DeepSeek V4.1 Flash 与 Opus 5.5 构建本地替代品，目的是替代其所称每月15美元的订阅。报告的基本交互是按住快捷键讲话，把文字输入任意应用；另列出去填充词、补标点、把散乱表达整理为列表、处理口头自我纠正，以及选中文本后口述改写的 Command Mode。

作者还声称支持按应用区分 Slack 和邮件风格、从纠正中学习的个人词典、其他语言的 Whisper 回退、完全离线、macOS/Windows/Linux 与 MIT 许可。原帖补查只确认这些文字及附视频，没有展开的代码地址、模型部署说明、平台测试或与原版的功能对照。本合集未观看完整视频或执行应用，不确认“全部功能免费”、离线隐私与许可承诺，也未确认使用 REA；不能与已有 Typeless 替代品合并。
