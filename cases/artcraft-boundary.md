# ArtCraft：不要把从零开发写成逆向 Adobe

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-13
阶段：相关项目

ArtCraft 被传播为创作软件的替代方向。官网说明其软件使用 Rust 从零编写，多款处于早期测试或开发中，不能将热门帖子解读成“AI 已完整逆向 Adobe”。作为相关的 AI 软件重建项目收录，不将其归为已完成的逆向成果。 已收录的 WordCraft、GridCraft 和 DeckCraft 分别重建 Word 风格文字处理器、Excel 风格电子表格与 PowerPoint 风格幻灯片软件，提供对应 Office 文件格式与 MCP 控制，公开 README 仍标为 alpha。10 月 12 日新增 PhotoCraft 的具体互通与验证材料：公开 README 说明 PSD 实现基于 Adobe 公开规范，UI、CLI、JSON 与 MCP 共用 500 多条命令；项目报告 309 个 psd-tools 样本中 307 个打开再保存后渲染一致，不是所有文件逐字节相同。PhotoCraft 仍为 early alpha，不能作为专业日用 Photoshop 替代，也不能据此称已反编译 Adobe。 2026年10月13日04:00–08:00窗口，一位用户报告亲自试用 PhotoCraft，具体指出面板无法浮动、色彩管理不透明、保存缺少压缩等格式选项、PSD打开较慢、活动图像焦点/蒙版读数及文字控制方面的问题，认为不适合专业工作。这是该用户的单次体验与评价，并非官方承认、本合集复现或所有版本的结论；补充既有 early-alpha 限制，不改变 Rust 从零重建、并非已反编译 Adobe 的边界。
