# ArtCraft：不要把从零开发写成逆向 Adobe

分类：应用与客户端 · 其他 AI 逆向
记录日期：2026-10-12
阶段：相关项目

ArtCraft 被传播为创作软件的替代方向。官网说明其软件使用 Rust 从零编写，多款处于早期测试或开发中，不能将热门帖子解读成“AI 已完整逆向 Adobe”。作为相关的 AI 软件重建项目收录，不将其归为已完成的逆向成果。 本周期补充 WordCraft：同一 ArtCraft 团队用 Rust 从公开规范和行为观察重建 Microsoft Word 风格文字处理器，提供 .docx 读写、修订、批注与 MCP 控制。公开 README 标为 alpha，仍需真实文档保真度与稳定性测试；传播帖称 pre-alpha，阶段以项目说明为准。它是相关软件重建方向，不能据此称已反编译 Word 或确认 AI 完成全部开发。
