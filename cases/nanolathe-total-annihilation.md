# Nanolathe：重新实现《横扫千军》游戏引擎

分类：游戏与游戏保存 · 其他 AI 逆向
记录日期：2026-10-13
阶段：待验证

Alexander Tanasie 分享 Nanolathe，称 Claude、Codex 与 DeepSeek 支持了《横扫千军》（Total Annihilation）引擎逆向。短链确实指向官网，对应公开 Go 仓库描述 clean-room 引擎与未完成兼容边界，并有供人和 Agent 贡献的研究规则。项目存在及重建目标可核查，但具体模型贡献比例仍主要来自传播帖；本次未运行。完整游戏需要用户自己的数据，不把引擎开源写成游戏内容免费。

证据：传播帖与公开仓库
阶段：持续开发、兼容性有缺口；未独立运行
