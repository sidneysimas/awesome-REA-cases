# 小米路由器：本地 Qwen 经 CGI 与 SSH 刷入 OpenWrt 的自述

分类：硬件与设备互通 · 其他 AI 逆向
记录日期：2026-10-18
阶段：待验证

10月18日20:17（北京时间），@BlockInsight214（王小庄）称让本地Qwen3.8-27B为自家小米路由器刷入OpenWrt，之前同样请求被Claude以安全理由拒绝。作者描述的路径不是网页上传bin，而是利用CGI中的方法传递启用SSH的payload，再经SSH写入固件。用途是把现有路由器换成自定义系统。

模型名称和成功结果均为作者说法。帖子中关于图标的表述含糊，未给CGI入口、路由器型号、原固件、OpenWrt镜像、分析日志或重启后验证，无法确认AI自行发现漏洞还是复用既有刷机方法，也不据此认定所有小米设备适用。Claude拒绝与本地模型行为只是这次自述，不支持所有开源模型没有护栏的概括。未确认REA，未执行目标或独立刷机。

10月18日候选快照2赞、179浏览；补取原帖确认作者与正文，不是设备验证。
