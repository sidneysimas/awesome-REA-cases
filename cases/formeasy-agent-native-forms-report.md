# FormEasy：声称研究 Google Forms 后做 Agent 原生表单

分类：应用与客户端 · 未确认使用 REA
记录日期：2026-10-18
阶段：相关项目

10月18日04:57（北京时间），Aawej Pathan（@atpaawej）发布 FormEasy，称自己逆向 Google Forms 后做出开源、Agent 原生的表单工具，powered by @AgentOnboardz。目标是让 AI Agent 在不打开浏览器、无需手动设置的情况下创建并发布表单，作者宣称用时两分钟。

可用正文没有给源码仓库、演示步骤、Google Forms 兼容格式、接口恢复过程或实际发布记录；也没有明说 AI 是否参与逆向本身。故按为 Agent 提供互通的相关项目收录，不将 Agent 作为用户等同于 AI 已完成逆向，不确认使用 REA，不保证与 Google Forms 等价或两分钟可重复实现。开源与功能均为作者报告，未独立测试。

候选快照0赞、22浏览；两分钟创建发布为作者说法。
