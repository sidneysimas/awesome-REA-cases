# Kaggle 代码向量：为 Gemma 4 后训练用 GNN 仿制未公开的 embedding 生成过程

分类：算法与功能重建 · 其他 AI 逆向
记录日期：2026-10-19
阶段：进行中

10月19日19:29（北京时间），@vbnakrani（Vaibhav）报告为Kaggle竞赛后训练Gemma 4时研究官方代码图与embedding。为使用SWE-Gym、SWE-smith等外部任务，需要生成与官方任务一致的图和每节点256维向量，供Agent相似代码搜索、邻居查询与局部子图三个工具使用。作者称在e2b做过有无这些工具的A/B，带工具解题更多，但未给题数或成绩。

调用图把函数、方法和类作为节点、调用作为边。作者称AST解析器已精确匹配全部127个官方图，约368k节点与226k边；更难的是未公布来源的约368k官方向量。根据相同文本在不同邻居下向量变化，作者推断生成器是使用节点及邻居原始代码的GNN；这是实验推断，不是主办方确认。测试约30个公开encoder（含EmbeddingGemma、CodeGemma、Qwen3-Embedding、UniXcoder、CodeBERT、CodeT5+、BGE、E5、nomic）均未找到原模型，报告R²为0.28–0.42，字符TF-IDF为0.40。

于是训练小GNN模仿官方向量。未调优时仓内排名一致度为0.84，但未见仓仅0.08–0.24，恰好限制外部数据用途。帖子说正在搜索损失、输入特征和深宽的60种配置，若仍不行可能删除相似搜索工具。没有竞赛可核名称、公开代码、向量、原始测量或留出划分，本合集未训练模型或重跑实验；精确图匹配与数值均归因作者，不认定成功恢复官方embedding或取得跨仓泛化。未确认REA。
