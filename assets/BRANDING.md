# REA Cases visual identity

An independent identity for this unofficial case collection, not an official REA logo.

- `rea-icon.svg`: vector master. Reverse arrow + code brackets, ink / off-white / lime.
- `rea-icon.png`: 1024 × 1024 square icon.
- `rea-social-preview.png`: 1280 × 640 GitHub social preview. Upload under repository Settings → General → Social preview.

Keep the preview free of case counts and update dates so it does not become stale.
Do not replace the repository owner's personal avatar with this project icon.
